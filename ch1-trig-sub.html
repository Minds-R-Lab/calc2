1.3 Trigonometric Substitution

Learning Objectives
  • Recognize when to apply trigonometric substitution (integrals with square roots of quadratic expressions)
  • Master the three cases: $\sqrt{a^2 - x^2}$, $\sqrt{a^2 + x^2}$, and $\sqrt{x^2 - a^2}$
  • Use Pythagorean identities to eliminate square roots
  • Construct and use reference triangles for back-substitution
  • Evaluate complex integrals involving $\sec^3 \theta$ and logarithmic terms

Trigonometric substitution is a specialized technique for evaluating integrals containing square roots of quadratic expressions. By replacing the variable with a trigonometric function, we can use Pythagorean identities to simplify expressions like $\sqrt{a^2 - x^2}$, $\sqrt{a^2 + x^2}$, and $\sqrt{x^2 - a^2}$.

Key Principle

Transform algebraic expressions involving square roots into trigonometric ones where Pythagorean identities apply, yielding polynomial-like integrals that are tractable.

Theory & Substitutions

Three Cases of Trigonometric Substitution

Case 1: Integrals containing $\sqrt{a^2 - x^2}$

Substitution: $x = a \sin \theta$, where $-\frac{\pi}{2} \leq \theta \leq \frac{\pi}{2}$

$$dx = a \cos \theta \, d\theta$$
$$\sqrt{a^2 - x^2} = \sqrt{a^2 - a^2 \sin^2 \theta} = \sqrt{a^2(1 - \sin^2 \theta)} = a\cos \theta$$

Why it works: The Pythagorean identity $1 - \sin^2 \theta = \cos^2 \theta$ eliminates the square root.

Case 2: Integrals containing $\sqrt{a^2 + x^2}$

Substitution: $x = a \tan \theta$, where $-\frac{\pi}{2} < \theta < \frac{\pi}{2}$

$$dx = a \sec^2 \theta \, d\theta$$
$$\sqrt{a^2 + x^2} = \sqrt{a^2 + a^2 \tan^2 \theta} = \sqrt{a^2(1 + \tan^2 \theta)} = a\sec \theta$$

Why it works: The Pythagorean identity $1 + \tan^2 \theta = \sec^2 \theta$ eliminates the square root.

Case 3: Integrals containing $\sqrt{x^2 - a^2}$

Substitution: $x = a \sec \theta$, where $0 \leq \theta < \frac{\pi}{2}$ or $\pi \leq \theta < \frac{3\pi}{2}$

$$dx = a \sec \theta \tan \theta \, d\theta$$
$$\sqrt{x^2 - a^2} = \sqrt{a^2 \sec^2 \theta - a^2} = \sqrt{a^2(\sec^2 \theta - 1)} = a\tan \theta$$

Why it works: The Pythagorean identity $\sec^2 \theta - 1 = \tan^2 \theta$ eliminates the square root.

Reference Triangle Method

💡 Pro Tip: The Reference Triangle

After integration, converting back to the original variable is easier using a reference triangle:

  • Draw a right triangle with the substitution as one side and angle $\theta$ marked
  • Use the Pythagorean theorem to find the third side
  • Use the triangle to express all trigonometric functions in terms of $x$ and $a$

This avoids the need to solve for $\theta$ explicitly!

⚠️ Common Mistake

Don't forget to include the differential $dx$ when substituting! Also, when back-substituting, be careful with the signs and domains of inverse trigonometric functions. The reference triangle helps ensure you get the signs right.

Step-by-Step Method

Trigonometric Substitution Algorithm
  1. Identify the form: Determine which case applies: $\sqrt{a^2 - x^2}$, $\sqrt{a^2 + x^2}$, or $\sqrt{x^2 - a^2}$
  2. Choose substitution: Apply the appropriate trigonometric substitution and find $dx$
  3. Substitute: Replace all instances of $x$ and $dx$ in the integral. Simplify using Pythagorean identities.
  4. Integrate: The integral now involves only trigonometric functions (usually polynomial-like in $\sin \theta$ or $\cos \theta$)
  5. Back-substitute: Use the reference triangle to express the answer in terms of the original variable $x$
  6. Simplify: Combine and simplify the final expression

Worked Examples

Example 1: $\int \frac{dx}{\sqrt{4 - x^2}}$

This contains $\sqrt{4 - x^2} = \sqrt{2^2 - x^2}$, so use Case 1.

Step 1: Identify $a = 2$

Step 2: Substitute $x = 2\sin \theta$, $dx = 2\cos \theta \, d\theta$

$$\sqrt{4 - x^2} = \sqrt{4 - 4\sin^2 \theta} = 2\cos \theta$$

Step 3: Substitute into the integral

$$\int \frac{dx}{\sqrt{4 - x^2}} = \int \frac{2\cos \theta \, d\theta}{2\cos \theta} = \int d\theta = \theta + C$$

Step 4: Back-substitute. Since $x = 2\sin \theta$, we have $\theta = \arcsin(x/2)$

$$\int \frac{dx}{\sqrt{4 - x^2}} = \arcsin\left(\frac{x}{2}\right) + C$$

Answer: $\boxed{\arcsin\left(\frac{x}{2}\right) + C}$

Solution Details ▼

This is the simplest trigonometric substitution example. The key insight is that $\sqrt{4 - 4\sin^2 \theta} = 2|\cos \theta| = 2\cos \theta$ (since $-\pi/2 \leq \theta \leq \pi/2$ ensures $\cos \theta \geq 0$). The substitution transforms the entire integral into a trivial form.

Example 2: $\int \frac{x^2}{\sqrt{x^2 + 9}} \, dx$

This contains $\sqrt{x^2 + 9} = \sqrt{x^2 + 3^2}$, so use Case 2.

Step 1: Identify $a = 3$

Step 2: Substitute $x = 3\tan \theta$, $dx = 3\sec^2 \theta \, d\theta$

$$\sqrt{x^2 + 9} = \sqrt{9\tan^2 \theta + 9} = 3\sec \theta$$

Step 3: Substitute into the integral

$$\int \frac{x^2}{\sqrt{x^2 + 9}} \, dx = \int \frac{9\tan^2 \theta}{3\sec \theta} \cdot 3\sec^2 \theta \, d\theta$$
$$= \int 9\tan^2 \theta \sec \theta \, d\theta$$

Step 4: Use $\tan^2 \theta = \sec^2 \theta - 1$

$$= 9\int (\sec^2 \theta - 1)\sec \theta \, d\theta = 9\int (\sec^3 \theta - \sec \theta) \, d\theta$$

These are standard integrals:

$$\int \sec \theta \, d\theta = \ln|\sec \theta + \tan \theta| + C$$
$$\int \sec^3 \theta \, d\theta = \frac{1}{2}(\sec \theta \tan \theta + \ln|\sec \theta + \tan \theta|) + C$$

Step 5: Combine (taking the antiderivative)

$$= 9\left[\frac{1}{2}(\sec \theta \tan \theta + \ln|\sec \theta + \tan \theta|) - \ln|\sec \theta + \tan \theta|\right] + C$$
$$= \frac{9}{2}\sec \theta \tan \theta - \frac{9}{2}\ln|\sec \theta + \tan \theta| + C$$

Step 6: Back-substitute using the reference triangle. From $x = 3\tan \theta$:

  • $\tan \theta = \frac{x}{3}$
  • $\sec \theta = \frac{\sqrt{x^2 + 9}}{3}$
$$= \frac{9}{2} \cdot \frac{\sqrt{x^2 + 9}}{3} \cdot \frac{x}{3} - \frac{9}{2}\ln\left|\frac{\sqrt{x^2 + 9}}{3} + \frac{x}{3}\right| + C$$
$$= \frac{x\sqrt{x^2 + 9}}{2} - \frac{9}{2}\ln\left|\frac{x + \sqrt{x^2 + 9}}{3}\right| + C$$

Answer: $\boxed{\frac{x\sqrt{x^2 + 9}}{2} - \frac{9}{2}\ln\left|\frac{x + \sqrt{x^2 + 9}}{3}\right| + C}$

Understanding This Complex Example ▼

This example demonstrates several important techniques:

  • The reference triangle is crucial: from $x = 3\tan \theta$, we draw a right triangle with opposite side $x$ and adjacent side 3, giving hypotenuse $\sqrt{x^2 + 9}$.
  • The integral of $\sec^3 \theta$ is a standard form that appears frequently in trigonometric substitution problems.
  • The logarithmic term in the final answer arises from the $\int \sec \theta \, d\theta$ component.

Example 3: $\int \frac{\sqrt{x^2 - 1}}{x} \, dx$

This contains $\sqrt{x^2 - 1} = \sqrt{x^2 - 1^2}$, so use Case 3.

Step 1: Identify $a = 1$

Step 2: Substitute $x = \sec \theta$, $dx = \sec \theta \tan \theta \, d\theta$

$$\sqrt{x^2 - 1} = \sqrt{\sec^2 \theta - 1} = \tan \theta$$

Step 3: Substitute into the integral

$$\int \frac{\sqrt{x^2 - 1}}{x} \, dx = \int \frac{\tan \theta}{\sec \theta} \sec \theta \tan \theta \, d\theta$$
$$= \int \tan^2 \theta \, d\theta$$

Step 4: Use $\tan^2 \theta = \sec^2 \theta - 1$

$$= \int (\sec^2 \theta - 1) \, d\theta = \tan \theta - \theta + C$$

Step 5: Back-substitute. From $x = \sec \theta$:

  • $\theta = \text{arcsec}(x)$
  • $\tan \theta = \sqrt{x^2 - 1}$
$$= \sqrt{x^2 - 1} - \text{arcsec}(x) + C$$

Answer: $\boxed{\sqrt{x^2 - 1} - \text{arcsec}(x) + C}$ or equivalently $\boxed{\sqrt{x^2 - 1} - \arccos\left(\frac{1}{x}\right) + C}$

Case 3 Details ▼

Case 3 is less common than Cases 1 and 2, but it's essential for integrals involving $\sqrt{x^2 - a^2}$. The key is recognizing that $x = \sec \theta$ naturally satisfies the restriction $|x| \geq 1$, and the resulting reference triangle has opposite side $\sqrt{x^2-1}$ and hypotenuse $x$.

Practice Problems

Practice Problem 1: $\int \frac{dx}{\sqrt{9 - x^2}}$

A simple Case 1 trigonometric substitution problem.

Show Solution ▼

Form: $\sqrt{9 - x^2} = \sqrt{3^2 - x^2}$ — Use Case 1 with $a = 3$

Substitute: $x = 3\sin \theta$, $dx = 3\cos \theta \, d\theta$

Simplify: $\sqrt{9 - x^2} = 3\cos \theta$

Integral: $\displaystyle \int \frac{3\cos \theta \, d\theta}{3\cos \theta} = \int d\theta = \theta + C$

Back-substitute: $\theta = \arcsin(x/3)$

Answer: $\displaystyle \arcsin\left(\frac{x}{3}\right) + C$

Practice Problem 2: $\int \frac{dx}{x^2\sqrt{x^2 + 4}}$

A Case 2 problem requiring careful manipulation of trigonometric functions.

Show Solution ▼

Form: $\sqrt{x^2 + 4} = \sqrt{x^2 + 2^2}$ — Use Case 2 with $a = 2$

Substitute: $x = 2\tan \theta$, $dx = 2\sec^2 \theta \, d\theta$

Simplify: $\sqrt{x^2 + 4} = 2\sec \theta$

Integral: $\displaystyle \int \frac{2\sec^2 \theta \, d\theta}{4\tan^2 \theta \cdot 2\sec \theta} = \frac{1}{4}\int \frac{\sec \theta}{\tan^2 \theta} \, d\theta$

Simplify: $\displaystyle \frac{1}{4}\int \frac{1}{\sin^2 \theta} \cos \theta \, d\theta = \frac{1}{4}\int \csc^2 \theta \cos \theta \, d\theta$

Using $\csc^2 \theta = 1/\sin^2 \theta$ and $\cos \theta = 1/\sec \theta$, after integration and back-substitution:

Answer: $\displaystyle -\frac{\sqrt{x^2+4}}{4x} + C$

Practice Problem 3: $\int \sqrt{x^2 - 4} \, dx$

A Case 3 problem where we integrate a power of the trigonometric substitution.

Show Solution ▼

Form: $\sqrt{x^2 - 4} = \sqrt{x^2 - 2^2}$ — Use Case 3 with $a = 2$

Substitute: $x = 2\sec \theta$, $dx = 2\sec \theta \tan \theta \, d\theta$

Simplify: $\sqrt{x^2 - 4} = 2\tan \theta$

Integral: $\displaystyle \int 2\tan \theta \cdot 2\sec \theta \tan \theta \, d\theta = 4\int \sec \theta \tan^2 \theta \, d\theta$

Use $\tan^2 \theta = \sec^2 \theta - 1$: $\displaystyle 4\int \sec \theta(\sec^2 \theta - 1) \, d\theta = 4\int (\sec^3 \theta - \sec \theta) \, d\theta$

Standard integrals: $\displaystyle 4\left[\frac{1}{2}(\sec \theta \tan \theta + \ln|\sec \theta + \tan \theta|) - \ln|\sec \theta + \tan \theta|\right]$

After back-substitution with $\sec \theta = x/2$ and $\tan \theta = \sqrt{x^2-4}/2$:

Answer: $\displaystyle \frac{x\sqrt{x^2-4}}{2} - 2\ln\left|x + \sqrt{x^2-4}\right| + C$ (plus constant adjustments)
