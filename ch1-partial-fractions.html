1.4 Partial Fractions Decomposition

Learning Objectives
  • Decompose rational functions into simpler partial fractions
  • Handle distinct linear factors, repeated linear factors, and irreducible quadratic factors
  • Solve systems of equations to find partial fraction coefficients
  • Integrate rational functions by integrating their partial fraction decomposition
  • Perform polynomial long division when necessary

Partial fraction decomposition is a technique for breaking down rational functions (ratios of polynomials) into simpler fractions that can be integrated term by term. This is particularly useful when the denominator factors into linear or irreducible quadratic factors.

Key Idea

A complex rational function can be written as a sum of simpler fractions, each with a lower-degree denominator, making integration straightforward.

Theory & Decomposition Rules

General Principle

Definition: Partial Fractions

If $\frac{P(x)}{Q(x)}$ is a rational function where $P(x)$ and $Q(x)$ are polynomials, we can decompose it as:

$$\frac{P(x)}{Q(x)} = \text{(polynomial)} + \text{(proper rational function)}$$

A proper rational function is one where the degree of the numerator is less than the degree of the denominator.

Case 1: Distinct Linear Factors

Case 1: Distinct Linear Factors

If the denominator factors as $Q(x) = (x - a_1)(x - a_2)\cdots(x - a_n)$ with distinct roots, then:

$$\frac{P(x)}{Q(x)} = \frac{A_1}{x - a_1} + \frac{A_2}{x - a_2} + \cdots + \frac{A_n}{x - a_n}$$

where $A_1, A_2, \ldots, A_n$ are constants found by solving a system of equations.

Case 2: Repeated Linear Factors

Case 2: Repeated Linear Factors

If $(x - a)$ appears $k$ times in the denominator, then include terms:

$$\frac{A_1}{x - a} + \frac{A_2}{(x - a)^2} + \cdots + \frac{A_k}{(x - a)^k}$$

Case 3: Irreducible Quadratic Factors

Case 3: Irreducible Quadratic Factors

If $ax^2 + bx + c$ is an irreducible quadratic (no real roots) that appears $k$ times, include terms:

$$\frac{A_1 x + B_1}{ax^2 + bx + c} + \frac{A_2 x + B_2}{(ax^2 + bx + c)^2} + \cdots + \frac{A_k x + B_k}{(ax^2 + bx + c)^k}$$
⚠️ Common Mistake

For irreducible quadratic factors, don't forget that the numerator must be linear (of the form $Ax + B$), not constant! Failing to include the $x$ term will lead to an incorrect number of equations.

Prerequisite: Long Division

When to Use Polynomial Long Division

If the degree of the numerator is greater than or equal to the degree of the denominator, perform polynomial long division first:

$$\frac{P(x)}{Q(x)} = D(x) + \frac{R(x)}{Q(x)}$$

where $D(x)$ is the quotient and $R(x)$ is the remainder with $\deg(R) < \deg(Q)$. Then decompose only $\frac{R(x)}{Q(x)}$ into partial fractions.

💡 Pro Tip

Always check the degrees first! If the numerator has degree $\geq$ the denominator, you must do long division before partial fractions.

Step-by-Step Method

Partial Fractions Algorithm
  1. Check degrees: If degree of numerator $\geq$ degree of denominator, use long division first.
  2. Factor the denominator: Factor $Q(x)$ into distinct and repeated linear factors, and irreducible quadratic factors.
  3. Set up the decomposition: Write the partial fraction form based on the factorization (Cases 1–3 above).
  4. Find constants: Multiply both sides by the common denominator $Q(x)$ and use one of these methods:
    • Substitution method: Substitute strategic values of $x$ (roots of factors) to isolate constants
    • Coefficient matching: Expand the right side and equate coefficients of like powers of $x$
    • Combination: Use substitution for some constants and coefficient matching for others
  5. Integrate: Integrate each partial fraction term separately
  6. Combine: Add the results and include the constant of integration

Worked Examples

Example 1: $\int \frac{3x + 5}{(x - 1)(x + 2)} \, dx$

The denominator has distinct linear factors and the numerator has lower degree.

Step 1: Set up the partial fraction decomposition

$$\frac{3x + 5}{(x - 1)(x + 2)} = \frac{A}{x - 1} + \frac{B}{x + 2}$$

Step 2: Multiply both sides by $(x - 1)(x + 2)$

$$3x + 5 = A(x + 2) + B(x - 1)$$

Step 3: Find $A$ and $B$ using substitution

Let $x = 1$:

$$3(1) + 5 = A(1 + 2) + B(0) \Rightarrow 8 = 3A \Rightarrow A = \frac{8}{3}$$

Let $x = -2$:

$$3(-2) + 5 = A(0) + B(-2 - 1) \Rightarrow -1 = -3B \Rightarrow B = \frac{1}{3}$$

Step 4: Write the decomposition

$$\frac{3x + 5}{(x - 1)(x + 2)} = \frac{8/3}{x - 1} + \frac{1/3}{x + 2}$$

Step 5: Integrate

$$\int \frac{3x + 5}{(x - 1)(x + 2)} \, dx = \frac{8}{3}\int \frac{dx}{x - 1} + \frac{1}{3}\int \frac{dx}{x + 2}$$
$$= \frac{8}{3}\ln|x - 1| + \frac{1}{3}\ln|x + 2| + C$$

Answer: $\boxed{\frac{8}{3}\ln|x - 1| + \frac{1}{3}\ln|x + 2| + C}$ or $\displaystyle \ln\left|(x-1)^{8/3}(x+2)^{1/3}\right| + C$

Solution Explanation ▼

This is the simplest case—distinct linear factors. The substitution method works perfectly because plugging in the roots eliminates one term at a time, leaving us with simple equations for each constant.

Example 2: $\int \frac{2x}{(x - 1)^2} \, dx$

The denominator has a repeated linear factor ($(x-1)^2$).

Step 1: Set up the partial fraction decomposition

$$\frac{2x}{(x - 1)^2} = \frac{A}{x - 1} + \frac{B}{(x - 1)^2}$$

Step 2: Multiply both sides by $(x - 1)^2$

$$2x = A(x - 1) + B$$

Step 3: Find $A$ and $B$

Let $x = 1$:

$$2(1) = 0 + B \Rightarrow B = 2$$

Expand and match coefficients: $2x = Ax - A + B$

Coefficient of $x$: $2 = A$

Step 4: Write the decomposition

$$\frac{2x}{(x - 1)^2} = \frac{2}{x - 1} + \frac{2}{(x - 1)^2}$$

Step 5: Integrate

$$\int \frac{2x}{(x - 1)^2} \, dx = 2\int \frac{dx}{x - 1} + 2\int \frac{dx}{(x - 1)^2}$$
$$= 2\ln|x - 1| + 2 \cdot \frac{(x-1)^{-1}}{-1} + C$$
$$= 2\ln|x - 1| - \frac{2}{x - 1} + C$$

Answer: $\boxed{2\ln|x - 1| - \frac{2}{x - 1} + C}$

Handling Repeated Factors ▼

For repeated factors, we include a partial fraction term for each power of the factor. Notice how the integration of $\frac{2}{(x-1)^2}$ uses the power rule: $\int (x-1)^{-2} dx = -1 \cdot (x-1)^{-1} = -\frac{1}{x-1}$.

Example 3: $\int \frac{x^2 + 1}{x(x^2 + 4)} \, dx$

The denominator has a linear factor $x$ and an irreducible quadratic factor $x^2 + 4$.

Step 1: Set up the partial fraction decomposition

$$\frac{x^2 + 1}{x(x^2 + 4)} = \frac{A}{x} + \frac{Bx + C}{x^2 + 4}$$

Step 2: Multiply both sides by $x(x^2 + 4)$

$$x^2 + 1 = A(x^2 + 4) + (Bx + C)x$$

Step 3: Find $A$, $B$, and $C$

Let $x = 0$:

$$0 + 1 = A(4) + 0 \Rightarrow A = \frac{1}{4}$$

Expand: $x^2 + 1 = Ax^2 + 4A + Bx^2 + Cx = (A + B)x^2 + Cx + 4A$

Coefficient of $x^2$: $1 = A + B \Rightarrow B = 1 - \frac{1}{4} = \frac{3}{4}$

Coefficient of $x$: $0 = C$

Step 4: Write the decomposition

$$\frac{x^2 + 1}{x(x^2 + 4)} = \frac{1/4}{x} + \frac{(3/4)x}{x^2 + 4}$$

Step 5: Integrate

$$\int \frac{x^2 + 1}{x(x^2 + 4)} \, dx = \frac{1}{4}\int \frac{dx}{x} + \frac{3}{4}\int \frac{x \, dx}{x^2 + 4}$$

For the second integral, let $u = x^2 + 4$, $du = 2x \, dx$:

$$= \frac{1}{4}\ln|x| + \frac{3}{4} \cdot \frac{1}{2}\ln|x^2 + 4| + C$$
$$= \frac{1}{4}\ln|x| + \frac{3}{8}\ln(x^2 + 4) + C$$

Answer: $\boxed{\frac{1}{4}\ln|x| + \frac{3}{8}\ln(x^2 + 4) + C}$ or $\displaystyle \ln\left|x^{1/4}(x^2+4)^{3/8}\right| + C$

Working with Quadratic Factors ▼

When an irreducible quadratic factor appears, the numerator of its partial fraction must be linear ($Bx + C$). The integral $\int \frac{x}{x^2+4} dx$ evaluates to $\frac{1}{2}\ln(x^2+4)$ using substitution. If the numerator had been constant, we'd need arctangent, but the linear numerator makes it a logarithm.

Practice Problems

Practice Problem 1: $\int \frac{5x - 2}{(x - 2)(x + 1)} \, dx$

A distinct linear factors problem similar to Example 1.

Show Solution ▼

Set up decomposition: $\displaystyle \frac{5x-2}{(x-2)(x+1)} = \frac{A}{x-2} + \frac{B}{x+1}$

Multiply by common denominator: $5x - 2 = A(x + 1) + B(x - 2)$

Substitute $x = 2$: $5(2) - 2 = A(3) \Rightarrow 8 = 3A \Rightarrow A = \frac{8}{3}$

Substitute $x = -1$: $5(-1) - 2 = B(-3) \Rightarrow -7 = -3B \Rightarrow B = \frac{7}{3}$

Integrate: $\displaystyle \int \frac{5x-2}{(x-2)(x+1)} \, dx = \frac{8}{3}\ln|x-2| + \frac{7}{3}\ln|x+1| + C$

Answer: $\displaystyle \frac{8}{3}\ln|x-2| + \frac{7}{3}\ln|x+1| + C$

Practice Problem 2: $\int \frac{x + 3}{(x + 1)^2} \, dx$

A repeated linear factors problem similar to Example 2.

Show Solution ▼

Set up decomposition: $\displaystyle \frac{x+3}{(x+1)^2} = \frac{A}{x+1} + \frac{B}{(x+1)^2}$

Multiply by common denominator: $x + 3 = A(x + 1) + B$

Substitute $x = -1$: $-1 + 3 = 0 + B \Rightarrow B = 2$

Coefficient of $x$: From $x + 3 = Ax + A + B$, we get $1 = A$

Integrate: $\displaystyle \int \frac{x+3}{(x+1)^2} \, dx = \int \frac{1}{x+1} \, dx + 2\int \frac{1}{(x+1)^2} \, dx$

$\displaystyle = \ln|x+1| + 2 \cdot \frac{(x+1)^{-1}}{-1} = \ln|x+1| - \frac{2}{x+1} + C$

Answer: $\displaystyle \ln|x+1| - \frac{2}{x+1} + C$

Practice Problem 3: $\int \frac{1}{x^3 - 1} \, dx$

An irreducible quadratic factor problem that's more challenging.

Show Solution ▼

Factor: $x^3 - 1 = (x - 1)(x^2 + x + 1)$ where $x^2 + x + 1$ is irreducible (discriminant is negative)

Set up decomposition: $\displaystyle \frac{1}{(x-1)(x^2+x+1)} = \frac{A}{x-1} + \frac{Bx+C}{x^2+x+1}$

Multiply by common denominator: $1 = A(x^2+x+1) + (Bx+C)(x-1)$

Substitute $x = 1$: $1 = A(3) \Rightarrow A = \frac{1}{3}$

Expand and match coefficients:

$1 = Ax^2 + Ax + A + Bx^2 - Bx + Cx - C$

$1 = (A+B)x^2 + (A-B+C)x + (A-C)$

Coefficient of $x^2$: $0 = \frac{1}{3} + B \Rightarrow B = -\frac{1}{3}$

Constant: $1 = \frac{1}{3} - C \Rightarrow C = -\frac{2}{3}$

Integrate: The first part gives $\frac{1}{3}\ln|x-1|$. The quadratic part requires completing the square and arctangent substitution.

Answer (simplified): $\displaystyle \frac{1}{3}\ln|x-1| - \frac{1}{6}\ln(x^2+x+1) - \frac{1}{\sqrt{3}}\arctan\left(\frac{2x+1}{\sqrt{3}}\right) + C$
