Chapter 6.2: Polar Coordinates

Learning Objectives
  • Understand polar coordinates and conversion between polar and rectangular forms
  • Recognize and sketch common polar curves (circles, cardioids, roses, spirals, lemniscates)
  • Find slopes of tangent lines to polar curves
  • Understand the advantages of polar coordinates for describing curves with radial symmetry
Definition: Polar Coordinates

Polar coordinates provide an alternative way to describe points in the plane. Instead of using rectangular coordinates $(x, y)$, we use polar coordinates $(r, \theta)$, where $r$ is the distance from the origin and $\theta$ is the angle from the positive x-axis.

Polar coordinates are particularly useful for describing curves with radial symmetry (circles, spirals, roses, cardioids) and for computing integrals in regions with circular or angular structure.

Theory

Theorem: Conversion Between Rectangular and Polar Coordinates

The conversion formulas are: $$x = r\cos\theta, \quad y = r\sin\theta$$ $$r^2 = x^2 + y^2, \quad \tan\theta = \frac{y}{x}$$

⚠️ Common Mistake

Note that $r$ can be negative; $r < 0$ means the point is in the opposite direction of angle $\theta$. Don't forget to consider negative values of $r$ when sketching polar curves.

Definition: Common Polar Curves

1. Circles: $r = a$ (circle of radius $a$ centered at origin)

2. Cardioid: $r = a(1 + \cos\theta)$ or $r = a(1 + \sin\theta)$

3. Rose curves: $r = a\cos(n\theta)$ or $r = a\sin(n\theta)$ (creates $n$ petals if $n$ is odd, $2n$ petals if $n$ is even)

4. Spiral: $r = a\theta$ (Archimedean spiral) or $r = ae^{b\theta}$ (logarithmic spiral)

5. Lemniscate: $r^2 = a^2\cos(2\theta)$

Theorem: Tangent Lines in Polar Coordinates

For a curve $r = f(\theta)$, the slope of the tangent line is: $$\frac{dy}{dx} = \frac{r'\sin\theta + r\cos\theta}{r'\cos\theta - r\sin\theta}$$ where $r' = \frac{dr}{d\theta}$.

The tangent line is horizontal when the numerator is 0, and vertical when the denominator is 0.

💡 Pro Tip

When converting from polar to rectangular form, multiply by $r$ strategically to introduce $r^2 = x^2 + y^2$ or $r\sin\theta = y$ or $r\cos\theta = x$. This often simplifies the equation significantly.

Method

For Converting Polar Equations to Rectangular Form:

  1. Use $x = r\cos\theta$, $y = r\sin\theta$, and $r^2 = x^2 + y^2$
  2. Substitute and simplify to eliminate $r$ and $\theta$.

For Sketching Polar Curves:

  1. Identify the type of curve (circle, rose, cardioid, etc.).
  2. Find key points by evaluating $r$ at special angles ($\theta = 0, \frac{\pi}{4}, \frac{\pi}{2}$, etc.).
  3. Check for symmetry about the x-axis, y-axis, or origin.
  4. Plot the points and sketch the curve, noting where $r$ changes sign.

For Finding Tangent Line Slopes:

  1. Compute $r' = \frac{dr}{d\theta}$
  2. At a specific angle $\theta_0$, use $\frac{dy}{dx} = \frac{r'\sin\theta_0 + r\cos\theta_0}{r'\cos\theta_0 - r\sin\theta_0}$

Examples

Example 1: Convert $x^2 + y^2 = 4$ to Polar Form

Express the circle in polar coordinates.

Solution ▼

Using $r^2 = x^2 + y^2$: $$x^2 + y^2 = 4 \implies r^2 = 4 \implies r = 2$$

In polar form, this is simply $r = 2$, a circle of radius 2 centered at the origin.

Example 2: Sketch the Cardioid $r = 1 + \cos\theta$

Describe and sketch the curve.

Solution ▼

Key values:

  • $\theta = 0$: $r = 1 + 1 = 2$
  • $\theta = \frac{\pi}{2}$: $r = 1 + 0 = 1$
  • $\theta = \pi$: $r = 1 - 1 = 0$ (cusps at origin)
  • $\theta = \frac{3\pi}{2}$: $r = 1 + 0 = 1$
  • $\theta = 2\pi$: $r = 1 + 1 = 2$

Symmetry: The curve is symmetric about the x-axis (since $\cos\theta$ is even).

Description: A heart-shaped curve (cardioid) with a cusp at the origin and maximum distance 2 from the origin (at $\theta = 0$, the rightmost point).

Example 3: Sketch the Rose Curve $r = \cos(3\theta)$

Identify the curve and describe its shape.

Solution ▼

The equation $r = \cos(n\theta)$ with $n = 3$ (odd) creates a rose curve with 3 petals.

Key observations:

  • $r = 0$ when $\cos(3\theta) = 0$, i.e., $3\theta = \frac{\pi}{2}, \frac{3\pi}{2}, \frac{5\pi}{2}, \ldots$
  • Maximum $r = 1$ when $\cos(3\theta) = 1$, i.e., $\theta = 0, \frac{2\pi}{3}, \frac{4\pi}{3}$
  • The curve has 3 petals emanating from the origin at angles $\theta = 0, \frac{2\pi}{3}, \frac{4\pi}{3}$.

Symmetry: The curve has 3-fold rotational symmetry about the origin.

Practice Problems

Practice Problem 1

Convert the polar equation $r = 2\sin\theta$ to rectangular form.

Show Solution ▼

Starting with $r = 2\sin\theta$, multiply both sides by $r$: $$r^2 = 2r\sin\theta$$

Using $r^2 = x^2 + y^2$ and $y = r\sin\theta$: $$x^2 + y^2 = 2y$$

Rearranging: $$x^2 + y^2 - 2y = 0$$ $$x^2 + (y-1)^2 = 1$$

This is a circle with center $(0, 1)$ and radius 1.

Practice Problem 2

For the curve $r = 1 + 2\cos\theta$, find all points where $\frac{dy}{dx} = 0$ (horizontal tangents).

Show Solution ▼

We have $r = 1 + 2\cos\theta$ and $r' = -2\sin\theta$.

The tangent line is horizontal when $\frac{dy}{dx} = 0$: $$\frac{dy}{dx} = \frac{r'\sin\theta + r\cos\theta}{r'\cos\theta - r\sin\theta} = 0$$

This requires: $$r'\sin\theta + r\cos\theta = 0$$ $$-2\sin^2\theta + (1 + 2\cos\theta)\cos\theta = 0$$ $$-2\sin^2\theta + \cos\theta + 2\cos^2\theta = 0$$ $$-2(1 - \cos^2\theta) + \cos\theta + 2\cos^2\theta = 0$$ $$-2 + 2\cos^2\theta + \cos\theta + 2\cos^2\theta = 0$$ $$4\cos^2\theta + \cos\theta - 2 = 0$$

Using the quadratic formula with $u = \cos\theta$: $$u = \frac{-1 \pm \sqrt{1 + 32}}{8} = \frac{-1 \pm \sqrt{33}}{8}$$

$u_1 = \frac{-1 + \sqrt{33}}{8} \approx 0.593$ and $u_2 = \frac{-1 - \sqrt{33}}{8} \approx -0.843$

Find the corresponding $\theta$ values and compute the points $(r, \theta)$ and convert to $(x, y)$.

Practice Problem 3

Sketch the curve $r = 2 - 2\cos\theta$ (a cardioid) and identify its key features.

Show Solution ▼

Key values:

  • $\theta = 0$: $r = 2 - 2 = 0$
  • $\theta = \frac{\pi}{2}$: $r = 2 - 0 = 2$
  • $\theta = \pi$: $r = 2 + 2 = 4$
  • $\theta = \frac{3\pi}{2}$: $r = 2 - 0 = 2$

Features:

  • Cusp at the origin ($\theta = 0$)
  • Maximum distance from origin: $r = 4$ at $\theta = \pi$
  • Symmetric about the x-axis
  • Heart-shaped (cardioid) with cusp pointing left
