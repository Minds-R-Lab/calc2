1.1 Integration by Parts

Learning Objectives
  • Understand the integration by parts formula and when to apply it
  • Master the LIATE rule for choosing $u$ and $dv$
  • Solve integrals involving products of functions, including repeated applications
  • Handle cyclic integration by parts (when the integral returns to itself)

Integration by parts is a powerful technique for finding antiderivatives of products of functions. It is derived from the product rule of differentiation and transforms difficult integrals into simpler ones.

Definition: Integration by Parts Formula

$$\int u \, dv = uv - \int v \, du$$

This formula allows us to convert a complex product integral into a simpler form, often repeatedly, to evaluate integrals that would otherwise be impossible to solve directly.

Theory & Derivation

Theorem: Product Rule to Integration by Parts

Integration by parts is derived from the product rule of differentiation:

$$\frac{d}{dx}[uv] = u'v + uv'$$

Integrating both sides and rearranging yields:

$$\int u \, dv = uv - \int v \, du$$

Choosing $u$ and $dv$: The LIATE Rule

Definition: LIATE Priority Rule

When applying integration by parts, the choice of $u$ and $dv$ is crucial. Use the LIATE rule to decide which factor should be $u$:

  • L — Logarithmic functions (e.g., $\ln x$)
  • I — Inverse trigonometric functions (e.g., $\arctan x$, $\arcsin x$)
  • A — Algebraic functions (e.g., $x$, $x^2$)
  • T — Trigonometric functions (e.g., $\sin x$, $\cos x$)
  • E — Exponential functions (e.g., $e^x$)

Choose $u$ to be the function that appears earliest in this list. The remaining factor is $dv$.

💡 Pro Tip

The LIATE rule works because it prioritizes functions that become simpler when differentiated (like logarithms and inverse trig functions) and reserves easily-integrable functions (like exponentials) for the $dv$ term.

⚠️ Common Mistake

Don't forget to include the constant of integration $C$ only at the final step, not at intermediate stages. Also, when computing $v$ from $dv$, you integrate without adding a constant.

Step-by-Step Method

Integration by Parts Algorithm
  1. Choose $u$ and $dv$: Use the LIATE rule to select $u$ from the integrand. Let $dv$ be the remaining part.
  2. Compute $du$ and $v$: Differentiate $u$ to get $du$. Integrate $dv$ to get $v$ (without adding $C$).
  3. Apply the Formula: Substitute into $\int u \, dv = uv - \int v \, du$.
  4. Simplify: Evaluate $uv$ and simplify the new integral $\int v \, du$. This integral should be simpler than the original.
  5. Add the Constant of Integration: After fully evaluating, add $C$ to the final answer.

Worked Examples

Example 1: $\int x e^x \, dx$

Step 1: Choose $u$ and $dv$

By LIATE, algebraic functions come before exponential, so:

$$u = x, \quad dv = e^x \, dx$$

Step 2: Compute $du$ and $v$

$$du = dx, \quad v = e^x$$

Step 3: Apply the formula

$$\int x e^x \, dx = x e^x - \int e^x \, dx$$

Step 4: Evaluate the remaining integral

$$\int x e^x \, dx = x e^x - e^x + C = e^x(x - 1) + C$$

Answer: $\boxed{xe^x - e^x + C}$ or $\boxed{e^x(x-1) + C}$

Full Solution Walkthrough ▼

This is a straightforward application of integration by parts with just one application of the formula.

Since $du = dx$ is simpler than $u = x$, and integrating $dv = e^x \, dx$ to get $v = e^x$ is elementary, we reduce the problem to computing $\int e^x \, dx = e^x$.

The final answer can be written as a product $e^x(x-1) + C$ by factoring out the common exponential term.

Example 2: $\int x^2 \sin x \, dx$ (Repeated Integration by Parts)

This requires integration by parts twice.

First Application:

$$u = x^2, \quad dv = \sin x \, dx$$
$$du = 2x \, dx, \quad v = -\cos x$$
$$\int x^2 \sin x \, dx = -x^2 \cos x - \int -\cos x \cdot 2x \, dx$$
$$= -x^2 \cos x + 2 \int x \cos x \, dx$$

Second Application (on $\int x \cos x \, dx$):

$$u = x, \quad dv = \cos x \, dx$$
$$du = dx, \quad v = \sin x$$
$$\int x \cos x \, dx = x \sin x - \int \sin x \, dx = x \sin x + \cos x$$

Combining Results:

$$\int x^2 \sin x \, dx = -x^2 \cos x + 2(x \sin x + \cos x) + C$$
$$= -x^2 \cos x + 2x \sin x + 2\cos x + C$$

Answer: $\boxed{-x^2 \cos x + 2x \sin x + 2\cos x + C}$

Solution Explanation ▼

This example demonstrates how repeated applications of integration by parts are necessary when the original integrand contains higher powers of algebraic functions.

The first application reduces the power of $x$ from 2 to 1. The second application reduces it further to 0, yielding a simple trigonometric integral we can evaluate directly.

This systematic reduction is why the LIATE rule is so effective: it always prioritizes the term that decreases in complexity under differentiation.

Example 3: $\int e^x \cos x \, dx$ (Cyclic Integration by Parts)

This integral returns to itself, creating a system we can solve.

First Application:

$$u = \cos x, \quad dv = e^x \, dx$$
$$du = -\sin x \, dx, \quad v = e^x$$
$$\int e^x \cos x \, dx = e^x \cos x - \int e^x (-\sin x) \, dx$$
$$= e^x \cos x + \int e^x \sin x \, dx$$

Second Application (on $\int e^x \sin x \, dx$):

$$u = \sin x, \quad dv = e^x \, dx$$
$$du = \cos x \, dx, \quad v = e^x$$
$$\int e^x \sin x \, dx = e^x \sin x - \int e^x \cos x \, dx$$

Solving the System: Let $I = \int e^x \cos x \, dx$

$$I = e^x \cos x + e^x \sin x - I$$
$$2I = e^x(\cos x + \sin x)$$
$$I = \frac{e^x(\cos x + \sin x)}{2} + C$$

Answer: $\boxed{\frac{e^x(\cos x + \sin x)}{2} + C}$

Understanding Cyclic Integration ▼

When integrating products of exponential and trigonometric functions, the integral often returns to a form proportional to itself after two applications of integration by parts.

Rather than continuing indefinitely, we solve algebraically: if $I$ represents our original integral and we derive an equation like $I = (\text{expression}) - I$, we can collect terms to get $2I = (\text{expression})$, then solve for $I$.

This technique is elegant and efficient for integrals that would otherwise seem circular.

Practice Problems

Practice Problem 1: $\int x \cos x \, dx$

Evaluate this integral using the standard integration by parts method.

Show Solution ▼

Choose: $u = x$, $dv = \cos x \, dx$

Then: $du = dx$, $v = \sin x$

Apply: $\int x \cos x \, dx = x \sin x - \int \sin x \, dx$

Evaluate: $\int x \cos x \, dx = x \sin x + \cos x + C$

Practice Problem 2: $\int x^2 e^{2x} \, dx$

This integral requires two applications of integration by parts.

Show Solution ▼

First Application: $u = x^2$, $dv = e^{2x} \, dx$

Then: $du = 2x \, dx$, $v = \frac{1}{2}e^{2x}$

Result: $\int x^2 e^{2x} \, dx = \frac{1}{2}x^2 e^{2x} - \int x e^{2x} \, dx$

Second Application (on $\int x e^{2x} \, dx$):

$u = x$, $dv = e^{2x} \, dx$

$du = dx$, $v = \frac{1}{2}e^{2x}$

$\int x e^{2x} \, dx = \frac{1}{2}x e^{2x} - \frac{1}{4}e^{2x}$

Final Answer: $\displaystyle \int x^2 e^{2x} \, dx = \frac{1}{2}x^2 e^{2x} - \frac{1}{2}x e^{2x} + \frac{1}{4}e^{2x} + C$

Or factored: $\displaystyle = \frac{e^{2x}}{4}(2x^2 - 2x + 1) + C$

Practice Problem 3: $\int \ln x \, dx$

This is a classic example where we treat the function cleverly with integration by parts.

Show Solution ▼

Choose: $u = \ln x$, $dv = dx$

Then: $du = \frac{1}{x} dx$, $v = x$

Apply: $\int \ln x \, dx = x \ln x - \int x \cdot \frac{1}{x} \, dx$

Evaluate: $\int \ln x \, dx = x \ln x - \int 1 \, dx = x \ln x - x + C$

Final Answer: $\boxed{x \ln x - x + C}$ or $\boxed{x(\ln x - 1) + C}$
