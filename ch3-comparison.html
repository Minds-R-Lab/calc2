3.3 Comparison Tests for Improper Integrals

For many improper integrals, finding the exact value is difficult or even impossible (e.g., $\int_1^{\infty} \frac{\sin^2 x}{x^2}\,dx$). However, we often only need to know whether an integral converges or diverges, not its exact value. Comparison tests allow us to determine convergence by comparing our integral to a simpler "reference" integral that we already understand.

The key insight: if a function is bounded above by a convergent integral, then our integral must also converge. Conversely, if a function is bounded below by a divergent integral, then our integral must also diverge.

Definition and Theory

Direct Comparison Test

Suppose $f$ and $g$ are continuous on $[a, \infty)$ with $0 \le f(x) \le g(x)$ for all $x \ge a$. Then:

If $\displaystyle \int_a^{\infty} g(x)\,dx$ converges, then $\displaystyle \int_a^{\infty} f(x)\,dx$ converges.

Equivalently, if $\displaystyle \int_a^{\infty} f(x)\,dx$ diverges, then $\displaystyle \int_a^{\infty} g(x)\,dx$ must also diverge.

Limit Comparison Test

Suppose $f$ and $g$ are positive and continuous on $[a, \infty)$, and suppose:

$$\lim_{x \to \infty} \frac{f(x)}{g(x)} = L$$

where $0 < L < \infty$ (i.e., $L$ is a positive finite number). Then:

$\displaystyle \int_a^{\infty} f(x)\,dx$ and $\displaystyle \int_a^{\infty} g(x)\,dx$ either both converge or both diverge.

The limit comparison test is more flexible than the direct comparison because we don't need exact inequalities—just knowledge of the asymptotic behavior of the ratio.

Common Comparison Functions

Useful "benchmark" functions for comparison:

  • $\frac{1}{x^p}$ (converges if $p > 1$; diverges if $p \le 1$)
  • $e^{-x}$ (converges)
  • $\frac{1}{\ln x}$ (diverges; grows very slowly)
  • $\frac{1}{x(\ln x)^p}$ (converges if $p > 1$; diverges if $p \le 1$)

Strategy for Choosing a Comparison Function

When applying a comparison test:

  1. Identify the dominant term in the numerator and denominator as $x \to \infty$.
  2. Simplify the function to its "leading behavior"—this becomes your comparison function $g(x)$.
  3. Apply either the direct comparison (if inequalities are obvious) or the limit comparison (if you know the limit of the ratio).

Method for Solving

Direct Comparison Test

  1. Choose a comparison function $g(x)$ where $\int_a^{\infty} g(x)\,dx$ is known to converge or diverge.
  2. Verify the inequality: Show that $0 \le f(x) \le g(x)$ for all $x \ge a$ (or at least for all $x$ sufficiently large).
  3. Apply the test:
    • If $\int g$ converges and $f \le g$, then $\int f$ converges.
    • If $\int f$ diverges and $f \le g$, then $\int g$ diverges.

Limit Comparison Test

  1. Choose a comparison function $g(x)$ where the behavior is known.
  2. Compute the limit: $$\lim_{x \to \infty} \frac{f(x)}{g(x)} = L$$
  3. Check the limit: If $0 < L < \infty$, then $f$ and $g$ have the same convergence behavior.
  4. Conclude: Determine the convergence of $g$ and apply that to $f$.

Key Insights

  • Both tests require that $f$ and $g$ are eventually positive (for large $x$).
  • The limit comparison test often works better when the functions have complicated forms.
  • For Type II integrals (discontinuities), similar comparison tests exist but use different inequalities near the discontinuity.

Worked Examples

Example 1: $\displaystyle \int_1^{\infty} \frac{1}{x^2+1}\,dx$ (Direct Comparison)

Solution:

  1. Choose a comparison: For $x \ge 1$, we have $x^2 + 1 \ge x^2$, so $\frac{1}{x^2+1} \le \frac{1}{x^2}$.
  2. Check the comparison function: We know that $\int_1^{\infty} \frac{1}{x^2}\,dx$ converges (it equals 1, by the $p$-test with $p=2 > 1$).
  3. Apply direct comparison: Since $0 \le \frac{1}{x^2+1} \le \frac{1}{x^2}$ and $\int_1^{\infty} \frac{1}{x^2}\,dx$ converges, we conclude that $\int_1^{\infty} \frac{1}{x^2+1}\,dx$ converges.

(We could even compute the exact value using arctangent: $\int_1^{\infty} \frac{1}{x^2+1}\,dx = \left[\arctan x\right]_1^{\infty} = \frac{\pi}{2} - \frac{\pi}{4} = \frac{\pi}{4}$, but the comparison test alone tells us convergence.)

Example 2: $\displaystyle \int_1^{\infty} \frac{x}{x^3+1}\,dx$ (Limit Comparison)

Solution:

  1. Identify the leading behavior: For large $x$, the function behaves like $\frac{x}{x^3} = \frac{1}{x^2}$.
  2. Choose a comparison: Let $g(x) = \frac{1}{x^2}$.
  3. Compute the limit: $$\lim_{x \to \infty} \frac{f(x)}{g(x)} = \lim_{x \to \infty} \frac{\frac{x}{x^3+1}}{\frac{1}{x^2}} = \lim_{x \to \infty} \frac{x \cdot x^2}{x^3+1} = \lim_{x \to \infty} \frac{x^3}{x^3+1} = \lim_{x \to \infty} \frac{1}{1 + 1/x^3} = 1$$
  4. Apply limit comparison: Since $\lim \frac{f}{g} = 1$ (which is in $(0, \infty)$), the two integrals have the same convergence behavior. We know $\int_1^{\infty} \frac{1}{x^2}\,dx$ converges, so $\int_1^{\infty} \frac{x}{x^3+1}\,dx$ converges.

Example 3: $\displaystyle \int_1^{\infty} \frac{\sin^2 x}{x^2}\,dx$ (Bounded Function)

Solution:

  1. Identify bounds: Since $0 \le \sin^2 x \le 1$ for all $x$, we have $$0 \le \frac{\sin^2 x}{x^2} \le \frac{1}{x^2}$$
  2. Check the comparison function: $\int_1^{\infty} \frac{1}{x^2}\,dx$ converges (by the $p$-test with $p=2$).
  3. Apply direct comparison: By the direct comparison test, $$\int_1^{\infty} \frac{\sin^2 x}{x^2}\,dx \quad \text{converges}$$

Note: Even though $\sin^2 x$ oscillates wildly, the $1/x^2$ decay is strong enough to ensure convergence. This shows the power of comparison tests—we don't need to know the exact value or detailed behavior of the integrand.

Practice Problems

Problem 1

Use a comparison test to determine whether the following integral converges or diverges: $$\int_2^{\infty} \frac{1}{x^2 - x}\,dx$$

Solution

For $x \ge 2$, we have $x^2 - x < x^2$, so $\frac{1}{x^2-x} > \frac{1}{x^2}$. However, this gives us the wrong inequality for the direct comparison test.

Instead, observe that for $x \ge 2$, we have $x^2 - x = x(x-1) \ge \frac{x^2}{2}$ (since $x - 1 \ge x/2$ for $x \ge 2$). Thus $\frac{1}{x^2-x} \le \frac{2}{x^2}$.

Since $\int_2^{\infty} \frac{1}{x^2}\,dx$ converges (by the $p$-test), and $\frac{1}{x^2-x} \le \frac{2}{x^2}$ for $x \ge 2$, the direct comparison test implies that $\int_2^{\infty} \frac{1}{x^2-x}\,dx$ converges.

Problem 2

Use the limit comparison test to determine convergence or divergence: $$\int_1^{\infty} \frac{3x + 2}{x^3 + x + 1}\,dx$$

Solution

For large $x$, the function behaves like $\frac{3x}{x^3} = \frac{3}{x^2}$. Let $g(x) = \frac{1}{x^2}$.

$$\lim_{x \to \infty} \frac{\frac{3x+2}{x^3+x+1}}{\frac{1}{x^2}} = \lim_{x \to \infty} \frac{(3x+2) \cdot x^2}{x^3+x+1}$$ $$= \lim_{x \to \infty} \frac{3x^3 + 2x^2}{x^3+x+1} = \lim_{x \to \infty} \frac{3 + 2/x}{1 + 1/x^2 + 1/x^3} = 3$$

Since the limit is 3 (a positive finite number) and $\int_1^{\infty} \frac{1}{x^2}\,dx$ converges, the limit comparison test says that $\int_1^{\infty} \frac{3x+2}{x^3+x+1}\,dx$ converges.

Problem 3

Use a comparison test to determine convergence or divergence: $$\int_1^{\infty} \frac{\sqrt{x}}{x^2 + 1}\,dx$$

Solution

For large $x$, $\sqrt{x}/x^2 \sim x^{1/2}/x^2 = x^{-3/2} = 1/x^{3/2}$. Let $g(x) = 1/x^{3/2}$.

$$\lim_{x \to \infty} \frac{\frac{\sqrt{x}}{x^2+1}}{\frac{1}{x^{3/2}}} = \lim_{x \to \infty} \frac{\sqrt{x} \cdot x^{3/2}}{x^2+1} = \lim_{x \to \infty} \frac{x^2}{x^2+1} = 1$$

Since the limit equals 1 and $\int_1^{\infty} x^{-3/2}\,dx$ converges (by the $p$-test with $p = 3/2 > 1$), the limit comparison test says that $\int_1^{\infty} \frac{\sqrt{x}}{x^2+1}\,dx$ converges.
