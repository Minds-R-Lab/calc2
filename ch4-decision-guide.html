4.6 Which Convergence Test Should I Use?

Learning Objectives
  • Recognize structural patterns in a series that point to specific convergence tests
  • Use a systematic decision process to select the most efficient test
  • Understand when multiple tests apply and how to choose between them

The hardest part of Chapter 4 isn't learning the individual tests — it's staring at a series on an exam and knowing which test to try. This page gives you three tools: a visual flowchart, an interactive wizard, and a quick-reference table. Master this decision process and series problems become routine.

Golden Rule: Always Start Here

Step 0: Check the Divergence Test first. If $\lim_{n\to\infty} a_n \neq 0$, the series diverges — done! If the limit IS zero, the Divergence Test is inconclusive and you must use another test.

The Decision Flowchart

Start at the top. Follow the arrows based on what your series looks like. Each path leads to the recommended convergence test.

Common Mistake

Students often forget: the Divergence Test can only prove divergence. If $\lim a_n = 0$, you have NOT shown convergence — you've only passed the first checkpoint. You still need another test! For example, $\sum 1/n$ has $a_n \to 0$ but diverges.

Quick-Reference Table

Bookmark this table. When you see a pattern from the left column, reach for the test on the right.

$\sum ar^n$ or $\sum ar^{n-1}$ $\sum \left(\frac{2}{3}\right)^n$, $\sum 5\cdot(-0.4)^n$ Geometric Series conv. iff $|r|<1$
$\sum \frac{1}{n^p}$ $\sum \frac{1}{n^2}$, $\sum \frac{1}{\sqrt{n}}$ P-Series conv. iff $p>1$
Partial sums telescope (cancel) $\sum \frac{1}{n(n+1)}$, $\sum \left(\frac{1}{n}-\frac{1}{n+1}\right)$ Telescoping — write out partial sums
$(-1)^n$ or $(-1)^{n+1}$ factor $\sum \frac{(-1)^n}{n}$, $\sum \frac{(-1)^{n+1}}{\sqrt{n}}$ Alternating Series Test
Contains $n!$ (factorial) $\sum \frac{n!}{3^n}$, $\sum \frac{2^n}{n!}$ Ratio Test
Contains $r^n$ or $(...)^n$ (exponential) $\sum \frac{3^n}{n^2}$, $\sum \left(\frac{n}{n+1}\right)^{n^2}$ Ratio or Root Test
Rational function of $n$ (polynomial/polynomial) $\sum \frac{3n+1}{n^3-n}$, $\sum \frac{n^2}{5n^4+2}$ Limit Comparison with $\sum 1/n^p$
$a_n \le b_n$ and you know $\sum b_n$ converges $\frac{1}{n^2+1} \le \frac{1}{n^2}$ (which converges) Direct Comparison
Contains $\ln n$ $\sum \frac{1}{n\ln n}$, $\sum \frac{\ln n}{n^2}$ Integral Test (usually)
$f(n)$ where $\int f(x)\,dx$ is doable $\sum \frac{1}{n^2+1}$, $\sum n e^{-n^2}$ Integral Test
Pro Tip: When Multiple Tests Work

Many series can be handled by more than one test. For exam efficiency: (1) the Ratio Test is your best all-around tool for series with factorials or exponentials, (2) the Limit Comparison Test is fastest for rational functions of $n$, and (3) the Integral Test is your fallback when nothing else fits cleanly.

Practice: Name That Test

For each series below, identify the convergence test you'd use before revealing the answer.

1. $\displaystyle\sum_{n=1}^{\infty} \frac{n^2}{3^n}$
Show Answer ▼

Ratio Test — The $3^n$ (exponential) in the denominator is the clue. Compute $\lim \frac{a_{n+1}}{a_n} = \frac{(n+1)^2}{3n^2} \cdot 1 = \frac{1}{3} < 1$. Converges.

2. $\displaystyle\sum_{n=1}^{\infty} \frac{3n^2+1}{2n^4-n+7}$
Show Answer ▼

Limit Comparison Test — Rational function of $n$. Dominant terms give $\frac{3n^2}{2n^4} = \frac{3}{2n^2}$. Compare with $\sum 1/n^2$ (converges, $p=2>1$). The limit of the ratio is $3/2 > 0$ and finite, so our series also converges.

3. $\displaystyle\sum_{n=1}^{\infty} \frac{(-1)^{n+1}}{n^{3/4}}$
Show Answer ▼

Alternating Series Test — The $(-1)^{n+1}$ is the giveaway. Check: $b_n = 1/n^{3/4}$ is decreasing and $b_n \to 0$. Converges conditionally (since $\sum 1/n^{3/4}$ diverges because $p = 3/4 < 1$).

4. $\displaystyle\sum_{n=2}^{\infty} \frac{1}{n\,\ln n}$
Show Answer ▼

Integral Test — The $\ln n$ factor is the hint. $\int_2^{\infty} \frac{dx}{x\ln x} = \ln(\ln x)\Big|_2^{\infty} = \infty$. Diverges.

5. $\displaystyle\sum_{n=0}^{\infty} \frac{n!}{5^n}$
Show Answer ▼

Ratio Test — Factorial! That's always Ratio Test territory. $\lim \frac{a_{n+1}}{a_n} = \lim \frac{(n+1)!}{5^{n+1}} \cdot \frac{5^n}{n!} = \lim \frac{n+1}{5} = \infty > 1$. Diverges.

6. $\displaystyle\sum_{n=1}^{\infty} \left(\frac{2n+1}{3n+4}\right)^n$
Show Answer ▼

Root Test — The entire term is raised to the $n$th power — perfect for Root Test. $\lim \sqrt[n]{a_n} = \lim \frac{2n+1}{3n+4} = \frac{2}{3} < 1$. Converges.

7. $\displaystyle\sum_{n=1}^{\infty} \frac{1}{n(n+2)}$
Show Answer ▼

Telescoping — Use partial fractions: $\frac{1}{n(n+2)} = \frac{1}{2}\left(\frac{1}{n} - \frac{1}{n+2}\right)$. Write out partial sums and watch terms cancel. Converges to $\frac{3}{4}$.

8. $\displaystyle\sum_{n=1}^{\infty} \frac{\cos(n\pi)}{n}$
Show Answer ▼

Alternating Series Test — Recognize that $\cos(n\pi) = (-1)^n$. So this is $\sum \frac{(-1)^n}{n}$, the alternating harmonic series. $b_n = 1/n$ is decreasing and $\to 0$. Converges conditionally.
