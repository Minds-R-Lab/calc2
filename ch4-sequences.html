Chapter 4.1: Sequences

Introduction

A sequence is a list of numbers arranged in a definite order. Sequences form the foundation for studying infinite series and are essential for understanding convergence and limits in calculus.

In this chapter, we explore:

  • Formal definition of sequences and their limits
  • Key theorems: Squeeze Theorem and Monotone Convergence Theorem
  • Bounded and monotonic sequences
  • Practical examples of important sequences

Theory

Definition of a Sequence

A sequence is a function \(a_n\) where \(n\) is a positive integer. We write it as \(\{a_n\}_{n=1}^{\infty}\) or simply \(\{a_n\}\).

A sequence \(\{a_n\}\) converges to \(L\) if for every \(\varepsilon > 0\), there exists \(N\) such that whenever \(n > N\), we have:

\(|a_n - L| < \varepsilon\)

We write \(\lim_{n \to \infty} a_n = L\) or \(a_n \to L\).

Squeeze Theorem

If \(\{a_n\}\), \(\{b_n\}\), and \(\{c_n\}\) are sequences such that \(a_n \le b_n \le c_n\) for all \(n\) beyond some point, and if \(\lim_{n \to \infty} a_n = L = \lim_{n \to \infty} c_n\), then \(\lim_{n \to \infty} b_n = L\).

Monotone Convergence Theorem

A sequence that is monotone (always increasing or always decreasing) and bounded must converge.

  • Monotone increasing: \(a_n \le a_{n+1}\) for all \(n\)
  • Monotone decreasing: \(a_n \ge a_{n+1}\) for all \(n\)
  • Bounded above: \(a_n \le M\) for some \(M\)
  • Bounded below: \(a_n \ge m\) for some \(m\)

Bounded and Monotonic Sequences

A sequence is:

  • Bounded: if there exist numbers \(m\) and \(M\) such that \(m \le a_n \le M\) for all \(n\)
  • Monotonically increasing: if \(a_n \le a_{n+1}\) for all \(n\)
  • Monotonically decreasing: if \(a_n \ge a_{n+1}\) for all \(n\)

The key result: A monotone sequence converges if and only if it is bounded.

Method: Finding Limits of Sequences

General Approach

  1. Analyze the formula: Look for patterns and dominant terms
  2. Apply algebraic techniques: Factor, divide by largest power, rationalize
  3. Use known limits: e.g., \(\lim_{n \to \infty} n^{1/n} = 1\), \(\lim_{n \to \infty} (1 + 1/n)^n = e\)
  4. Apply theorems: Squeeze, Monotone Convergence, etc.
  5. Conclude: State the limit or show divergence

Key Limits to Remember

  • \(\lim_{n \to \infty} \frac{1}{n^p} = 0\) for any \(p > 0\)
  • \(\lim_{n \to \infty} c^{1/n} = 1\) for any \(c > 0\)
  • \(\lim_{n \to \infty} n^{1/n} = 1\)
  • \(\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e\)
  • \(\lim_{n \to \infty} r^n = 0\) if \(|r| < 1\)

Examples

Example 1: \(a_n = \frac{n}{n+1}\)

Find \(\lim_{n \to \infty} \frac{n}{n+1}\).

Solution: Divide numerator and denominator by \(n\):

\(\lim_{n \to \infty} \frac{n}{n+1} = \lim_{n \to \infty} \frac{1}{1 + \frac{1}{n}} = \frac{1}{1+0} = 1\)

As \(n\) increases, the sequence approaches 1.

Example 2: \(a_n = \frac{(-1)^n}{n}\)

Find \(\lim_{n \to \infty} \frac{(-1)^n}{n}\).

Solution: We have:

  • When \(n\) is odd: \(a_n = -\frac{1}{n}\)
  • When \(n\) is even: \(a_n = \frac{1}{n}\)

Both subsequences approach 0. By the Squeeze Theorem, \(-\frac{1}{n} \le \frac{(-1)^n}{n} \le \frac{1}{n}\) and since both bounds approach 0, we have:

\(\lim_{n \to \infty} \frac{(-1)^n}{n} = 0\)

Example 3: \(a_n = \left(1 + \frac{1}{n}\right)^n\)

Find \(\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n\).

Solution: This is one of the most important limits in calculus. It is the definition of the number \(e\):

\(\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e \approx 2.71828\)

This fundamental constant appears throughout mathematics, physics, and engineering.

Practice Problems

Problem 1

Find \(\lim_{n \to \infty} \frac{3n^2 + 2n}{5n^2 - 1}\).

Solution

Divide numerator and denominator by \(n^2\):

\(\lim_{n \to \infty} \frac{3n^2 + 2n}{5n^2 - 1} = \lim_{n \to \infty} \frac{3 + \frac{2}{n}}{5 - \frac{1}{n^2}} = \frac{3 + 0}{5 - 0} = \frac{3}{5}\)

Problem 2

Determine whether the sequence \(a_n = \frac{\sin(n)}{n}\) converges, and if so, find the limit.

Solution

Since \(|\sin(n)| \le 1\) for all \(n\), we have:

\(-\frac{1}{n} \le \frac{\sin(n)}{n} \le \frac{1}{n}\)

By the Squeeze Theorem, since \(\lim_{n \to \infty} \frac{1}{n} = 0\) and \(\lim_{n \to \infty} -\frac{1}{n} = 0\), we have:

\(\lim_{n \to \infty} \frac{\sin(n)}{n} = 0\)

Problem 3

Is the sequence \(a_n = \frac{(-1)^{n+1} \cdot n}{n+1}\) monotonic? Is it bounded?

Solution

Monotonicity: The sequence is not monotonic because it alternates in sign:

  • \(a_1 = \frac{1}{2}\)
  • \(a_2 = -\frac{2}{3}\)
  • \(a_3 = \frac{3}{4}\)

Boundedness: Yes, it is bounded. For all \(n\):

\(\left|\frac{(-1)^{n+1} \cdot n}{n+1}\right| = \frac{n}{n+1} < 1\)

So \(-1 < a_n < 1\) for all \(n\).
