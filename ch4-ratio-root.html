Chapter 4.5: Ratio & Root Tests

Learning Objectives
  • Apply the Ratio Test to series with factorials and exponentials
  • Apply the Root Test to series with powers and nth roots
  • Recognize when the Ratio/Root tests are inconclusive
  • Choose the appropriate test based on series structure

Introduction

The Ratio Test and Root Test are particularly effective for series involving factorials, exponentials, and powers. Unlike comparison tests, these tests are self-contained and don't require knowledge of other series' convergence.

In this chapter:

  • The Ratio Test: for factorials and products
  • The Root Test: for powers and nested exponents
  • When tests are inconclusive ($L = 1$)
  • Which test to use when

Theory

Theorem: The Ratio Test

For a series $\sum a_n$ where $a_n \neq 0$, let

$$L = \lim_{n \to \infty} \left|\frac{a_{n+1}}{a_n}\right|$$

Then:

  • If $L < 1$: the series converges absolutely
  • If $L > 1$: the series diverges
  • If $L = 1$: the test is inconclusive (use another test)
Theorem: The Root Test

For a series $\sum a_n$, let

$$L = \lim_{n \to \infty} \sqrt[n]{|a_n|}$$

Then:

  • If $L < 1$: the series converges absolutely
  • If $L > 1$: the series diverges
  • If $L = 1$: the test is inconclusive
Comparison of Tests
Test Best For Key Feature
Ratio Test Factorials, products Ratios of consecutive terms
Root Test Powers, nested roots nth roots of terms
Ratio Test: Inconclusive p-series, logarithmic Use comparison or integral test
Root Test: Inconclusive p-series, polynomial Use comparison or integral test
Why $L = 1$ is Inconclusive

When $L = 1$, the test cannot determine convergence because:

  • $\sum \frac{1}{n}$ (harmonic, diverges): $L = \lim \frac{1/(n+1)}{1/n} = 1$
  • $\sum \frac{1}{n^2}$ (converges): $L = \lim \frac{1/(n+1)^2}{1/n^2} = 1$

Both have $L = 1$, but one converges and one diverges. Different tests are needed.

💡 Pro Tip

The Ratio Test is often easier to compute with factorials (they simplify nicely). The Root Test shines when you have $n$-th powers, especially when the exponent depends on $n$.

Method: When to Use Which Test

Choosing the Right Test

  1. Factorials present? Use Ratio Test
    • Examples: $\sum \frac{n!}{n^n}$, $\sum \frac{n!}{2^n}$
  2. Exponentials with powers? Use Ratio Test or Root Test
    • Examples: $\sum \frac{2^n}{n^2}$, $\sum n^n e^{-n}$
  3. Nested powers or n-th roots? Use Root Test
    • Examples: $\sum \left(\frac{n}{2n+1}\right)^n$, $\sum \left(\sqrt[n]{n}\right)^n$
  4. Simple powers (polynomials)? Use p-series or Comparison
    • Ratio/Root tests will give $L = 1$
  5. Get $L = 1$? Try Integral, Comparison, or Limit Comparison Test
Computing Limits

For Ratio Test:

Simplify $\frac{a_{n+1}}{a_n}$ algebraically before taking the limit

For Root Test:

Use $\lim_{n \to \infty} n^{1/n} = 1$ and other known limits

⚠️ Common Mistake

When computing $\left|\frac{a_{n+1}}{a_n}\right|$, include the absolute value! This matters for alternating series. Also, always simplify algebraically BEFORE taking the limit; plugging limits into unsimplified expressions often leads to indeterminate forms.

Examples

Example 1: Ratio Test with Factorial $\sum_{n=1}^{\infty} \frac{n!}{n^n}$

Determine if $\sum_{n=1}^{\infty} \frac{n!}{n^n}$ converges or diverges.

Solution ▼

Use the Ratio Test.

$$\left|\frac{a_{n+1}}{a_n}\right| = \frac{(n+1)!}{(n+1)^{n+1}} \cdot \frac{n^n}{n!}$$

$$= \frac{(n+1) \cdot n!}{(n+1) \cdot (n+1)^n} \cdot \frac{n^n}{n!} = \frac{n^n}{(n+1)^n} = \left(\frac{n}{n+1}\right)^n$$

Taking the limit:

$$L = \lim_{n \to \infty} \left(\frac{n}{n+1}\right)^n = \lim_{n \to \infty} \left(\frac{1}{1 + 1/n}\right)^n = \frac{1}{e} \approx 0.368$$

Since $L = \frac{1}{e} < 1$, the series converges absolutely.

Example 2: Ratio Test with Exponential $\sum_{n=0}^{\infty} \frac{2^n}{n!}$

Determine if $\sum_{n=0}^{\infty} \frac{2^n}{n!}$ converges or diverges.

Solution ▼

Use the Ratio Test.

$$\left|\frac{a_{n+1}}{a_n}\right| = \frac{2^{n+1}}{(n+1)!} \cdot \frac{n!}{2^n} = \frac{2}{n+1}$$

Taking the limit:

$$L = \lim_{n \to \infty} \frac{2}{n+1} = 0 < 1$$

Since $L = 0 < 1$, the series converges absolutely.

(Note: This series is $e^2 \approx 7.389$, which you may recognize as part of the Taylor series for $e^x$)

Example 3: Root Test with Power $\sum_{n=1}^{\infty} \left(\frac{n}{2n+1}\right)^n$

Determine if $\sum_{n=1}^{\infty} \left(\frac{n}{2n+1}\right)^n$ converges or diverges.

Solution ▼

Use the Root Test.

$$\sqrt[n]{|a_n|} = \sqrt[n]{\left(\frac{n}{2n+1}\right)^n} = \frac{n}{2n+1}$$

Taking the limit:

$$L = \lim_{n \to \infty} \frac{n}{2n+1} = \lim_{n \to \infty} \frac{1}{2 + 1/n} = \frac{1}{2}$$

Since $L = \frac{1}{2} < 1$, the series converges absolutely.

Practice Problems

Practice Problem 1

Use the Ratio Test to determine convergence of $\sum_{n=1}^{\infty} \frac{(-1)^n n^3}{4^n}$.

Show Solution ▼

We have $a_n = \frac{(-1)^n n^3}{4^n}$.

$$\left|\frac{a_{n+1}}{a_n}\right| = \frac{(n+1)^3}{4^{n+1}} \cdot \frac{4^n}{n^3} = \frac{(n+1)^3}{4n^3}$$

Taking the limit:

$$L = \lim_{n \to \infty} \frac{(n+1)^3}{4n^3} = \lim_{n \to \infty} \frac{1}{4}\left(1 + \frac{1}{n}\right)^3 = \frac{1}{4} < 1$$

Since $L < 1$, the series converges absolutely.

Practice Problem 2

Use the Root Test to determine convergence of $\sum_{n=1}^{\infty} \frac{n^2}{3^n}$.

Show Solution ▼

We have $a_n = \frac{n^2}{3^n}$.

$$\sqrt[n]{|a_n|} = \sqrt[n]{\frac{n^2}{3^n}} = \frac{n^{2/n}}{3}$$

Recall that $\lim_{n \to \infty} n^{1/n} = 1$, so $\lim_{n \to \infty} n^{2/n} = 1$.

$$L = \lim_{n \to \infty} \frac{n^{2/n}}{3} = \frac{1}{3} < 1$$

Since $L < 1$, the series converges absolutely.

Practice Problem 3

Apply the Ratio Test to $\sum_{n=1}^{\infty} \frac{1}{n}$ and explain why it is inconclusive.

Show Solution ▼

We have $a_n = \frac{1}{n}$.

$$\left|\frac{a_{n+1}}{a_n}\right| = \frac{1/(n+1)}{1/n} = \frac{n}{n+1}$$

$$L = \lim_{n \to \infty} \frac{n}{n+1} = 1$$

Since $L = 1$, the Ratio Test is inconclusive. We must use another test, such as the Integral Test or Divergence Test, which show that the harmonic series diverges.
