1.2 Trigonometric Integrals

Trigonometric integrals involve integrating products and powers of sine and cosine functions. While these may appear complicated, systematic techniques can transform them into manageable forms using trigonometric identities and substitution strategies.

Key Strategy: Use parity of exponents (odd vs. even) and fundamental trigonometric identities to simplify the integrals.

Theory & Identities

Odd Power Strategy

For integrals with odd powers of sine or cosine, factor out one function and use the Pythagorean identity:

$$\sin^2 x + \cos^2 x = 1$$

For odd powers of $\sin x$: Factor out $\sin x$ and convert even powers to cosine.

$$\sin^{2k+1} x = \sin^{2k} x \cdot \sin x = (\sin^2 x)^k \sin x = (1 - \cos^2 x)^k \sin x$$

For odd powers of $\cos x$: Factor out $\cos x$ and convert even powers to sine.

$$\cos^{2k+1} x = \cos^{2k} x \cdot \cos x = (\cos^2 x)^k \cos x = (1 - \sin^2 x)^k \cos x$$

Even Power Strategy

For integrals with even powers, use the half-angle formulas:

$$\sin^2 x = \frac{1 - \cos 2x}{2}, \quad \cos^2 x = \frac{1 + \cos 2x}{2}$$

These formulas reduce the power of the trigonometric function, making the integral more tractable.

Products of Tangent and Secant

For integrals of $\tan^m x \sec^n x$, use the identities:

$$\sec^2 x = 1 + \tan^2 x, \quad \frac{d}{dx}[\tan x] = \sec^2 x, \quad \frac{d}{dx}[\sec x] = \sec x \tan x$$

Strategy: If $n$ is even, factor out $\sec^2 x$ and convert. If $m$ is odd, factor out $\sec x \tan x$ and convert using $\sec^2 x = 1 + \tan^2 x$.

Solution Methods

For $\int \sin^m x \cos^n x \, dx$ with at least one odd exponent:

  1. If $m$ is odd: Factor as $\sin^m x = \sin^{m-1} x \sin x = (1 - \cos^2 x)^{(m-1)/2} \sin x$
  2. Substitute $u = \cos x$, so $du = -\sin x \, dx$
  3. The integral becomes a polynomial in $u$ (with no more trigonometry)
  4. Integrate and substitute back

For $\int \sin^m x \cos^n x \, dx$ with both exponents even:

  1. Use half-angle formulas: $\sin^2 x = \frac{1 - \cos 2x}{2}$ and $\cos^2 x = \frac{1 + \cos 2x}{2}$
  2. Expand and simplify using products of cosines of multiples of $x$
  3. Repeat until all exponents are reduced to one
  4. Integrate directly

For $\int \tan^m x \sec^n x \, dx$:

  1. If $n$ is even and positive: Factor out $\sec^2 x$, substitute $u = \tan x$
  2. If $m$ is odd: Factor out $\sec x \tan x$, substitute $u = \sec x$
  3. Convert remaining terms using $\sec^2 x = 1 + \tan^2 x$

Worked Examples

Example 1: $\int \sin^3 x \cos^2 x \, dx$

The exponent of $\sin x$ is odd (3), so we use the odd power strategy.

Step 1: Factor out $\sin x$ and use $\sin^2 x = 1 - \cos^2 x$

$$\int \sin^3 x \cos^2 x \, dx = \int \sin^2 x \cos^2 x \sin x \, dx$$
$$= \int (1 - \cos^2 x) \cos^2 x \sin x \, dx$$

Step 2: Let $u = \cos x$, so $du = -\sin x \, dx$

$$= \int (1 - u^2) u^2 (-du) = -\int (u^2 - u^4) \, du$$

Step 3: Integrate

$$= -\left(\frac{u^3}{3} - \frac{u^5}{5}\right) + C = -\frac{u^3}{3} + \frac{u^5}{5} + C$$

Step 4: Substitute back $u = \cos x$

$$= -\frac{\cos^3 x}{3} + \frac{\cos^5 x}{5} + C$$

Answer: $\boxed{\frac{\cos^5 x}{5} - \frac{\cos^3 x}{3} + C}$

Example 2: $\int \sin^2 x \cos^2 x \, dx$

Both exponents are even, so we use the half-angle formulas.

Step 1: Apply half-angle formulas

$$\sin^2 x \cos^2 x = \frac{1 - \cos 2x}{2} \cdot \frac{1 + \cos 2x}{2}$$

Step 2: Multiply

$$= \frac{(1 - \cos 2x)(1 + \cos 2x)}{4} = \frac{1 - \cos^2 2x}{4}$$

Step 3: Apply half-angle formula again

$$= \frac{1}{4} \left(1 - \frac{1 + \cos 4x}{2}\right) = \frac{1}{4} \left(\frac{1 - \cos 4x}{2}\right)$$
$$= \frac{1 - \cos 4x}{8}$$

Step 4: Integrate

$$\int \sin^2 x \cos^2 x \, dx = \int \frac{1 - \cos 4x}{8} \, dx$$
$$= \frac{1}{8}\left(x - \frac{\sin 4x}{4}\right) + C = \frac{x}{8} - \frac{\sin 4x}{32} + C$$

Answer: $\boxed{\frac{x}{8} - \frac{\sin 4x}{32} + C}$

Example 3: $\int \tan^3 x \sec x \, dx$

The exponent of $\tan x$ is odd, so we factor out $\sec x \tan x$.

Step 1: Rewrite and use $\tan^2 x = \sec^2 x - 1$

$$\int \tan^3 x \sec x \, dx = \int \tan^2 x \sec x \tan x \, dx$$
$$= \int (\sec^2 x - 1) \sec x \tan x \, dx$$

Step 2: Let $u = \sec x$, so $du = \sec x \tan x \, dx$

$$= \int (u^2 - 1) \, du$$

Step 3: Integrate

$$= \frac{u^3}{3} - u + C$$

Step 4: Substitute back $u = \sec x$

$$= \frac{\sec^3 x}{3} - \sec x + C$$

Answer: $\boxed{\frac{\sec^3 x}{3} - \sec x + C}$

Practice Problems

Problem 1: $\int \sin^5 x \, dx$

Solution

Rewrite: $\sin^5 x = \sin^4 x \sin x = (1 - \cos^2 x)^2 \sin x$

Substitute: Let $u = \cos x$, $du = -\sin x \, dx$

Integral becomes: $\displaystyle -\int (1 - u^2)^2 \, du = -\int (1 - 2u^2 + u^4) \, du$

Integrate: $\displaystyle -\left(u - \frac{2u^3}{3} + \frac{u^5}{5}\right) + C$

Answer: $\displaystyle -\cos x + \frac{2\cos^3 x}{3} - \frac{\cos^5 x}{5} + C$

Problem 2: $\int \cos^4 x \, dx$

Solution

Use half-angle formula: $\cos^2 x = \frac{1 + \cos 2x}{2}$

Square: $\cos^4 x = \left(\frac{1 + \cos 2x}{2}\right)^2 = \frac{1 + 2\cos 2x + \cos^2 2x}{4}$

Apply formula again: $\cos^2 2x = \frac{1 + \cos 4x}{2}$

Combine: $\cos^4 x = \frac{1}{4}\left(1 + 2\cos 2x + \frac{1 + \cos 4x}{2}\right) = \frac{3 + 4\cos 2x + \cos 4x}{8}$

Integrate: $\displaystyle \frac{3x}{8} + \frac{4\sin 2x}{16} + \frac{\sin 4x}{32} + C = \frac{3x}{8} + \frac{\sin 2x}{4} + \frac{\sin 4x}{32} + C$

Problem 3: $\int \sin^2 x \sin 2x \, dx$

Solution

Use identity: $\sin 2x = 2\sin x \cos x$

Rewrite: $\int \sin^2 x \cdot 2\sin x \cos x \, dx = 2\int \sin^3 x \cos x \, dx$

Substitute: Let $u = \sin x$, $du = \cos x \, dx$

Integral becomes: $\displaystyle 2\int u^3 \, du = 2 \cdot \frac{u^4}{4} = \frac{u^4}{2} + C$

Answer: $\displaystyle \frac{\sin^4 x}{2} + C$
