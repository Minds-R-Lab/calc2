2.1 Area Between Curves

Area with respect to x

$$A = \int_a^b [f(x) - g(x)]\,dx$$
where $f(x) \ge g(x)$ on $[a,b]$. Find intersection points first!

Area with absolute value

$$A = \int_a^b |f(x) - g(x)|\,dx$$
Use when you're unsure which function is on top. Split at intersection points.

Area with respect to y

$$A = \int_c^d [f(y) - g(y)]\,dy$$
Integrate with respect to $y$ when functions are easier to solve for $x$, or region is tall and narrow.

2.2 Volumes: Disk & Washer Method

Disk Method (around x-axis)

$$V = \pi\int_a^b [R(x)]^2\,dx$$
$R(x)$ is the distance from the axis to the curve. Don't forget to square the radius!

Disk Method (around y-axis)

$$V = \pi\int_c^d [R(y)]^2\,dy$$
Same idea but integrate with respect to $y$.

Washer Method (around x-axis)

$$V = \pi\int_a^b \left([R(x)]^2 - [r(x)]^2\right)\,dx$$
$R(x)$ = outer radius, $r(x)$ = inner radius. Use when there's a hole in the middle.

Washer Method (around y-axis)

$$V = \pi\int_c^d \left([R(y)]^2 - [r(y)]^2\right)\,dy$$
Same idea with $dy$ instead of $dx$.

2.3 Volumes: Shell Method

Shell Method (around y-axis)

$$V = 2\pi\int_a^b x \cdot f(x)\,dx$$
$x$ = radius of shell, $f(x)$ = height. Use $dx$ and integrate with respect to $x$.

Shell Method (general)

$$V = 2\pi\int (\text{radius})(\text{height})\,d(\text{thickness})$$
Useful when washer method leads to complicated integrals.

2.4 Arc Length & Surface Area

Arc Length

$$L = \int_a^b \sqrt{1 + [f'(x)]^2}\,dx$$
Total length of the curve from $x=a$ to $x=b$. The $f'(x)$ term accounts for slope changes.

Arc Length (with respect to y)

$$L = \int_c^d \sqrt{1 + [g'(y)]^2}\,dy$$
Use when $x$ is a function of $y$.

Surface Area of Revolution (around x-axis)

$$S = 2\pi\int_a^b f(x)\sqrt{1+[f'(x)]^2}\,dx$$
$f(x)$ = distance from axis. Area of cylindrical band = $2\pi r \cdot ds$.

Surface Area of Revolution (around y-axis)

$$S = 2\pi\int_c^d g(y)\sqrt{1+[g'(y)]^2}\,dy$$
Integrate with respect to $y$.

Common Mistakes Gallery

Learn from the errors students make most often. Red = wrong, Green = correct.

Mistake #1: Forgetting to find intersection points before setting up the integral
✗ Wrong

$y = x^2$ and $y = x$. Area: $\int_0^1 (x - x^2)\,dx$

Assumed bounds were 0 and 1 without checking!

✓ Correct

Set $x^2 = x$, solve: $x(x-1) = 0$

Intersection points: $x = 0$ and $x = 1$

Then compute $\int_0^1 (x - x^2)\,dx$

Why? Without finding intersections, you don't know the bounds and might integrate the wrong region. Always solve $f(x) = g(x)$ first!
Mistake #2: Confusing which function is on top vs bottom
✗ Wrong

Area between $y = \sqrt{x}$ and $y = x^2$ from 0 to 1:

$A = \int_0^1 (x^2 - \sqrt{x})\,dx$ (negative!

✓ Correct

Check: at $x = 0.25$, $\sqrt{0.25} = 0.5$ and $(0.25)^2 = 0.0625$

So $\sqrt{x} > x^2$ on $(0,1)$

$A = \int_0^1 (\sqrt{x} - x^2)\,dx$ (positive!)

Why? Area is always positive. Use $A = \int |f(x) - g(x)|\,dx$ to be safe, or test a point to see which is larger.
Mistake #3: Confusing disk and shell method setup — mixing up radius and height
✗ Wrong

For $y = x^2$, rotating around the y-axis using shells:

$V = 2\pi \int_0^2 x^2 \cdot x\,dx$ (wrong formula!)

✓ Correct

Shell method: $V = 2\pi \int_0^2 (\text{radius}) \cdot (\text{height})\,dx$

Radius = $x$, Height = $x^2$ (function value)

$V = 2\pi \int_0^2 x \cdot x^2\,dx = 2\pi \int_0^2 x^3\,dx$

Why? In shell method, radius is the distance from the axis of rotation, and height is the function value. Don't confuse them!
Mistake #4: Forgetting the $2\pi$ factor in shell method
✗ Wrong

$V = \int_0^2 x \cdot x^2\,dx$ (missing $2\pi$!)

This gives arc length, not volume.

✓ Correct

$V = 2\pi \int_0^2 x \cdot x^2\,dx$

The $2\pi$ comes from the circumference of each cylindrical shell.

Why? Each shell wraps around the axis with circumference $2\pi r$. The $2\pi$ is essential for computing volume!
Mistake #5: Not squaring the radius in the disk/washer method
✗ Wrong

For $y = \sqrt{x}$ rotated around the x-axis:

$V = \pi \int_0^4 \sqrt{x}\,dx$ (missing square!)

✓ Correct

Area of disk = $\pi R^2$, so:

$V = \pi \int_0^4 (\sqrt{x})^2\,dx = \pi \int_0^4 x\,dx$

Why? The cross-sectional area of a disk is $\pi r^2$, not $\pi r$. Always square the radius!
Mistake #6: Using the wrong variable of integration
✗ Wrong

Area between $x = y^2$ and $x = 4$ (bounded region is horizontal):

$A = \int_0^4 (4 - y^2)\,dy$ (using $dy$ but function is in $x$!)

✓ Correct

Solve for $y$: $y = \pm\sqrt{x}$. It's easier to use $dy$:

$A = \int_{-2}^2 (4 - y^2)\,dy$ (correct variable and bounds)

Why? The choice of $dx$ vs $dy$ affects the setup. Pick the variable that makes the region easy to describe.

2.1 Area Between Curves

Formal Definition: The area between two curves $f(x)$ and $g(x)$ from $x=a$ to $x=b$ (where $f(x) \ge g(x)$) is given by $A = \int_a^b [f(x) - g(x)]\,dx$.
🎯 The simple version: Imagine two roads on a map, one above the other. The area between them is like painting the ground between the roads. We add up infinitely many thin vertical strips, each with width $dx$ and height (top road minus bottom road). That's what the integral does!
Analogy: You're filling in a region between two curves like coloring between two lines in a coloring book. The integral measures how much ink you need.

2.2 Disk & Washer Method

Formal Definition: When rotating a region around an axis, the volume is $V = \pi\int_a^b [R(x)]^2\,dx$ (disk) or $V = \pi\int_a^b \{[R(x)]^2 - [r(x)]^2\}\,dx$ (washer).
💿 The simple version: Imagine stacking coins or washers (coins with holes). Each thin slice has a circular cross-section. The volume is the sum of all these circular slices. The disk method is like stacking pancakes, while the washer method is like stacking donuts (with a hole in the middle).
Analogy: To measure the volume of a vase by rotating a profile around an axis: stack very thin circular slices and add them up. The radius changes as you go up, so each slice has a different area.

2.3 Shell Method

Formal Definition: When rotating a region around an axis, an alternative is the shell method: $V = 2\pi\int_a^b x \cdot f(x)\,dx$, which uses cylindrical shells instead of disks.
🎪 The simple version: Imagine wrapping up concentric cylindrical shells (like tin cans nested inside each other). Each shell is thin, with circumference $2\pi r$ and height $f(x)$. Instead of stacking disks, we're stacking hollow cylinders. This often leads to easier integrals!
Analogy: Instead of slicing a layer cake horizontally (disks), imagine wrapping it in concentric paper shells. The circumference and height of each shell tells you the volume.

2.4 Arc Length & Surface Area

Formal Definition: Arc length: $L = \int_a^b \sqrt{1 + [f'(x)]^2}\,dx$. Surface area of revolution: $S = 2\pi\int_a^b f(x)\sqrt{1+[f'(x)]^2}\,dx$.
📏 The simple version: Arc length is like measuring the distance along a curve. If the curve were a string, how long would it be? The term $\sqrt{1 + [f'(x)]^2}$ is the "speed" at which the curve moves — it accounts for both horizontal and vertical changes. For surface area, we wrap that curve around an axis like wallpaper on a cylinder, and the factor $2\pi f(x)$ is the circumference.
Analogy: Arc length: measuring the length of a hiking trail that goes up and down hills. Surface area: taking that trail and wrapping it around a pole to create a surface (like wallpaper on a cylinder).
