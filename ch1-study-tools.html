1.1 Integration by Parts

Core Formula

$$\int u\, dv = uv - \int v\, du$$
Choose $u$ and $dv$ using the LIATE priority rule.

LIATE Priority (choose $u$ first)

$$\mathbf{L} \to \mathbf{I} \to \mathbf{A} \to \mathbf{T} \to \mathbf{E}$$
Logarithmic, Inverse trig, Algebraic, Trig, Exponential. Pick $u$ as the type that comes first.

Definite Integral Version

$$\int_a^b u\, dv = \Big[uv\Big]_a^b - \int_a^b v\, du$$
Apply the boundary term $[uv]_a^b$ before evaluating the remaining integral.

Cyclic (Boomerang) Pattern

$$I = f(x) - g(x) + I \;\Rightarrow\; I = \frac{f(x) - g(x)}{2} + C$$
When by-parts returns the original integral $I$, solve algebraically for $I$. Common with $e^x \sin x$, $e^x \cos x$.

1.2 Trigonometric Integrals

$\sin^n x \cos^m x$ — odd power of $\sin$

$$\text{Save one } \sin x, \text{ convert rest: } \sin^2 x = 1 - \cos^2 x$$
Substitute $u = \cos x$, $du = -\sin x\, dx$.

$\sin^n x \cos^m x$ — odd power of $\cos$

$$\text{Save one } \cos x, \text{ convert rest: } \cos^2 x = 1 - \sin^2 x$$
Substitute $u = \sin x$, $du = \cos x\, dx$.

$\sin^n x \cos^m x$ — both even

$$\sin^2 x = \tfrac{1 - \cos 2x}{2}, \quad \cos^2 x = \tfrac{1 + \cos 2x}{2}$$
Use half-angle identities to reduce powers. May need to apply repeatedly.

$\tan^n x \sec^m x$ Strategy

$$\sec^2 x = 1 + \tan^2 x, \quad \frac{d}{dx}\tan x = \sec^2 x$$
Even power of $\sec$: save $\sec^2 x$, convert rest to $\tan$. Odd power of $\tan$: save $\sec x \tan x$.

1.3 Trigonometric Substitution

$\sqrt{a^2 - x^2}$

$$x = a\sin\theta, \quad dx = a\cos\theta\, d\theta$$
Result: $\sqrt{a^2 - x^2} = a\cos\theta$. Use when you see $a^2 - x^2$ under a root.

$\sqrt{a^2 + x^2}$

$$x = a\tan\theta, \quad dx = a\sec^2\theta\, d\theta$$
Result: $\sqrt{a^2 + x^2} = a\sec\theta$. Common in arc-length and distance problems.

$\sqrt{x^2 - a^2}$

$$x = a\sec\theta, \quad dx = a\sec\theta\tan\theta\, d\theta$$
Result: $\sqrt{x^2 - a^2} = a\tan\theta$. Used with expressions like $\sqrt{x^2 - 9}$.

1.4 Partial Fractions

Distinct Linear Factors

$$\frac{P(x)}{(x-a)(x-b)} = \frac{A}{x-a} + \frac{B}{x-b}$$
Each linear factor gets one constant. Use cover-up method: $A = P(a)/(a-b)$.

Repeated Linear Factor

$$\frac{P(x)}{(x-a)^3} = \frac{A}{x-a} + \frac{B}{(x-a)^2} + \frac{C}{(x-a)^3}$$
Repeated factor of multiplicity $k$ contributes $k$ terms with increasing powers.

Irreducible Quadratic Factor

$$\frac{P(x)}{(x^2+bx+c)} = \frac{Ax+B}{x^2+bx+c}$$
Quadratic factor gets $Ax+B$ in numerator. Integrate by completing the square $\to$ arctan.

Key Integration Results

$$\int \frac{dx}{x-a} = \ln|x-a|+C, \quad \int \frac{dx}{x^2+a^2} = \frac{1}{a}\arctan\frac{x}{a}+C$$
These are the building blocks after partial fraction decomposition.

Common Mistakes Gallery

Learn from the errors students make most often. Red = wrong, Green = correct.

Mistake #1: Wrong LIATE choice in Integration by Parts
✗ Wrong

For $\int x \ln x\, dx$:

Let $u = x$, $dv = \ln x\, dx$

Problem: $\int \ln x\, dx$ is hard to integrate as $dv$!

✓ Correct

For $\int x \ln x\, dx$:

Let $u = \ln x$ (L before A), $dv = x\, dx$

Then $du = \frac{1}{x}dx$, $v = \frac{x^2}{2}$

Why? LIATE says Logarithmic before Algebraic. Always pick $u$ as the function that simplifies when differentiated.
Mistake #2: Forgetting to convert back from $\theta$ after trig substitution
✗ Wrong

$\int \frac{dx}{\sqrt{4-x^2}}$ with $x = 2\sin\theta$:

$$= \theta + C$$

Final answer left in terms of $\theta$!

✓ Correct

$$= \theta + C = \arcsin\frac{x}{2} + C$$

Since $x = 2\sin\theta$, we get $\theta = \arcsin(x/2)$. Always convert back to $x$.

Why? The original integral was in terms of $x$, so the answer must be too. Draw a reference triangle to convert back.
Mistake #3: Forgetting long division before partial fractions
✗ Wrong

$\int \frac{x^3 + 1}{x^2 - 1}\, dx$

Directly decomposing $\frac{x^3+1}{(x-1)(x+1)} = \frac{A}{x-1} + \frac{B}{x+1}$

Degree of numerator $\geq$ denominator!

✓ Correct

First divide: $\frac{x^3+1}{x^2-1} = x + \frac{x+1}{x^2-1}$

Then decompose the proper fraction $\frac{x+1}{(x-1)(x+1)} = \frac{1}{x-1}$

Why? Partial fractions only works on proper fractions (degree of numerator < degree of denominator). Always check and do polynomial long division first.
Mistake #4: Wrong identity for even powers of sine/cosine
✗ Wrong

$\int \sin^2 x\, dx$

Using $\sin^2 x = 1 - \cos^2 x$

This just trades one even power for another — you're going in circles!

✓ Correct

Using the half-angle identity:

$\sin^2 x = \frac{1 - \cos 2x}{2}$

$= \frac{x}{2} - \frac{\sin 2x}{4} + C$

Why? The Pythagorean identity $\sin^2 x + \cos^2 x = 1$ doesn't reduce the power — it just shifts it. You need the half-angle (double-angle) identities to actually lower the degree.
Mistake #5: Dropping the absolute value in $\ln$
✗ Wrong

$$\int \frac{dx}{x-3} = \ln(x-3) + C$$

Missing absolute value bars!

✓ Correct

$$\int \frac{dx}{x-3} = \ln|x-3| + C$$

The absolute value ensures the logarithm is defined for $x < 3$ as well.

Why? $\ln(x)$ is only defined for $x > 0$, but $\frac{1}{x}$ exists for all $x \neq 0$. The absolute value extends the antiderivative to negative values.

Explain Like I'm 5

Simple, intuitive explanations next to the formal definitions. Click the purple button to toggle.

1.1 Integration by Parts

Formal Definition: If $u = f(x)$ and $v = g(x)$ are differentiable, then $$\int u\, dv = uv - \int v\, du$$ This reverses the product rule: $d(uv) = u\, dv + v\, du$.
🤝 The simple version: Integration by parts is the product rule running backwards. When you have two functions multiplied together inside an integral, you pick one to differentiate (make simpler) and one to integrate. You're basically trading a hard integral for an easier one.
Analogy: Imagine you're trying to carry two heavy boxes at once. Integration by parts says: "Put down one box (differentiate $u$), pick up the other differently (integrate $dv$), and the job becomes easier." The LIATE rule tells you which box to put down first — always the one that gets lighter fastest when you set it down.

1.2 Trigonometric Integrals

Formal Definition: Integrals of the form $\int \sin^n x \cos^m x\, dx$ are solved using Pythagorean identities ($\sin^2 x + \cos^2 x = 1$) and half-angle formulas to reduce powers, combined with $u$-substitution.
🎯 The simple version: When you see powers of sin and cos multiplied together, your goal is simple: get everything in terms of one trig function so you can do a basic $u$-substitution.
The recipe: Got an odd power? Great — peel off one copy (like peeling a banana), convert the rest using $\sin^2 + \cos^2 = 1$, then substitute. Both powers even? Use the half-angle trick to cut every power in half. It's like repeatedly breaking a problem in half until it's small enough to solve.

1.3 Trigonometric Substitution

Formal Definition: For integrands containing $\sqrt{a^2 - x^2}$, $\sqrt{a^2 + x^2}$, or $\sqrt{x^2 - a^2}$, substitute $x = a\sin\theta$, $x = a\tan\theta$, or $x = a\sec\theta$ respectively, using the Pythagorean identity to eliminate the radical.
🪄 The simple version: Square roots with $x^2$ inside them are ugly. Trig substitution is a magic trick to make the square root disappear. You replace $x$ with a trig expression that, thanks to the Pythagorean theorem ($\sin^2 + \cos^2 = 1$), makes everything under the root simplify perfectly.
Analogy: Think of $\sqrt{a^2 - x^2}$ as one side of a right triangle. When you say $x = a\sin\theta$, you're literally building a right triangle where the hypotenuse is $a$ and one leg is $x$. The remaining leg — the one you couldn't simplify — is automatically $a\cos\theta$. The square root was just the Pythagorean theorem in disguise!

1.4 Partial Fractions

Formal Definition: Any proper rational function $P(x)/Q(x)$ (with $\deg P < \deg Q$) can be decomposed into a sum of simpler fractions whose denominators are the factors of $Q(x)$, each of which can be integrated individually.
🍕 The simple version: Partial fractions is like un-adding fractions. In school, you learned to combine $\frac{1}{2} + \frac{1}{3} = \frac{5}{6}$. Now you're going backwards: given $\frac{5}{6}$, break it back into $\frac{1}{2} + \frac{1}{3}$. Why? Because each small piece is trivially easy to integrate — they all become $\ln$ or $\arctan$.
Analogy: Imagine a complicated fraction is a pizza that someone already cut and reassembled. You need to figure out the original slices. Each factor in the denominator tells you one slice shape. Once you find the pieces, integrating each one is like eating a single slice — easy!
