Chapter 2.3: Shell Method

Introduction

Learning Objectives
  • Understand how the shell method uses cylindrical shells instead of disks
  • Apply the shell method for vertical and horizontal axes of revolution
  • Identify when to use shell method versus disk/washer method
  • Set up shell integrals with correct radius and height
  • Calculate volumes using the shell method formula

The shell method is an alternative to the disk/washer method for finding volumes of solids of revolution. Instead of slicing perpendicular to the axis of revolution, we slice parallel to it, creating cylindrical shells.

The shell method is particularly useful when the disk/washer method would require integrating with respect to a variable that is more complicated to express.

Theory

Definition: Shell Method Formula (Vertical Shells)

When revolving a region around the y-axis, we can use vertical cylindrical shells:

$$V = 2\pi \int_a^b x \cdot f(x) \, dx$$

where $f(x)$ is the height of the shell at position $x$, and $x$ is the distance (radius) from the axis of revolution.

Definition: General Shell Method

For a region between two curves $y = f(x)$ and $y = g(x)$ with $f(x) \geq g(x)$, revolved around the y-axis:

$$V = 2\pi \int_a^b x \cdot [f(x) - g(x)] \, dx$$

Definition: Shells Around Non-Standard Axes

When revolving around a vertical line $x = c$, the radius of the shell is $|x - c|$:

$$V = 2\pi \int_a^b |x - c| \cdot f(x) \, dx$$

When revolving around a horizontal line, use horizontal shells and integrate with respect to $y$.

💡 Pro Tip

The shell method integrates the circumference $(2\pi r)$ times the height $(h)$ times an infinitesimal thickness $(dr)$. Think of "unrolling" a cylindrical shell to see it as a flat rectangle.

Method: Setting Up Shell Integrals

Steps for Shell Method
  1. Identify the axis of revolution
  2. Determine the bounds of integration (in the direction perpendicular to the axis)
  3. Find the radius of a thin shell at position $x$: $p(x)$ (distance to the axis)
  4. Find the height of the shell: $h(x) = f(x) - g(x)$ (or just $f(x)$ if one boundary is the axis)
  5. Set up the integral: $V = 2\pi \int_a^b p(x) h(x) \, dx$
  6. Evaluate
Key Formula: Shell Volume

Volume of a thin shell:

\text{Circumference} \times \text{Height} \times \text{Thickness} = 2\pi r h \, dr

⚠️ Common Mistake

Don't confuse the radius $p(x)$ with the height $h(x)$. The radius is the distance from the axis of rotation to the shell, while the height is measured perpendicular to the axis. For rotation around the y-axis, the radius is typically $x$ and the height is $f(x) - g(x)$ or just $f(x)$.

Examples

Example 1: Revolve $y = x^2$ From 0 to 2 About the y-axis

Find the volume when the region under $y = x^2$ from $x = 0$ to $x = 2$ is revolved about the y-axis.

Solution ▼

Setup:

At position $x$, the radius of the shell is $p(x) = x$, and the height is $h(x) = x^2$.

$$V = 2\pi \int_0^2 x \cdot x^2 \, dx = 2\pi \int_0^2 x^3 \, dx$$

Evaluation:

$$V = 2\pi \left[\frac{x^4}{4}\right]_0^2 = 2\pi \cdot \frac{16}{4} = 8\pi$$

Example 2: Revolve Region Between $y = x$ and $y = x^2$ About the y-axis

Find the volume when the region between $y = x$ (above) and $y = x^2$ (below) from $x = 0$ to $x = 1$ is revolved about the y-axis.

Solution ▼

Setup:

At position $x$, the radius is $p(x) = x$, and the height is $h(x) = x - x^2$.

$$V = 2\pi \int_0^1 x(x - x^2) \, dx = 2\pi \int_0^1 (x^2 - x^3) \, dx$$

Evaluation:

$$V = 2\pi \left[\frac{x^3}{3} - \frac{x^4}{4}\right]_0^1 = 2\pi \left(\frac{1}{3} - \frac{1}{4}\right) = 2\pi \cdot \frac{1}{12} = \frac{\pi}{6}$$

Example 3: Revolve $y = x^2$ From 0 to 2 About $x = 3$

Find the volume when the region under $y = x^2$ from $x = 0$ to $x = 2$ is revolved about the vertical line $x = 3$.

Solution ▼

Setup:

At position $x$, the distance from the line $x = 3$ is $p(x) = 3 - x$ (since $0 \leq x \leq 2 < 3$). The height is $h(x) = x^2$.

$$V = 2\pi \int_0^2 (3 - x) \cdot x^2 \, dx = 2\pi \int_0^2 (3x^2 - x^3) \, dx$$

Evaluation:

$$V = 2\pi \left[x^3 - \frac{x^4}{4}\right]_0^2 = 2\pi \left(8 - 4\right) = 8\pi$$

Practice Problems

Practice Problem 1

Find the volume of the solid obtained by revolving the region under $y = \sqrt{x}$ from $x = 0$ to $x = 4$ about the y-axis using the shell method.

Show Solution ▼

At position $x$, radius is $x$ and height is $\sqrt{x}$.

$$V = 2\pi \int_0^4 x \cdot \sqrt{x} \, dx = 2\pi \int_0^4 x^{3/2} \, dx$$ $$= 2\pi \left[\frac{2}{5}x^{5/2}\right]_0^4 = 2\pi \cdot \frac{2}{5} \cdot 32 = \frac{128\pi}{5}$$

Practice Problem 2

Find the volume obtained by revolving the region bounded by $y = 2 - x$, $y = 0$, and $x = 0$ about the y-axis.

Show Solution ▼

The line $y = 2 - x$ goes from $(0,2)$ to $(2,0)$.

At position $x$, radius is $x$ and height is $2 - x$.

$$V = 2\pi \int_0^2 x(2 - x) \, dx = 2\pi \int_0^2 (2x - x^2) \, dx$$ $$= 2\pi \left[x^2 - \frac{x^3}{3}\right]_0^2 = 2\pi \left(4 - \frac{8}{3}\right) = \frac{8\pi}{3}$$

Practice Problem 3

Find the volume obtained by revolving the region under $y = e^x$ from $x = 0$ to $x = 1$ about the y-axis.

Show Solution ▼

At position $x$, radius is $x$ and height is $e^x$.

$$V = 2\pi \int_0^1 x e^x \, dx$$

Using integration by parts: $u = x$, $dv = e^x dx$, so $du = dx$, $v = e^x$.

$$\int x e^x \, dx = xe^x - \int e^x \, dx = xe^x - e^x = e^x(x - 1)$$

$$V = 2\pi [e^x(x-1)]_0^1 = 2\pi [(e(1-1)) - (e^0(0-1))]$$ $$= 2\pi [0 - (-1)] = 2\pi$$
