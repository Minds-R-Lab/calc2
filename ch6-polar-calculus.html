Chapter 6.3: Calculus in Polar Coordinates

Learning Objectives
  • Compute areas enclosed by polar curves
  • Find areas between two polar curves
  • Calculate arc length for polar curves
  • Apply integration techniques to polar regions with radial symmetry
Overview

Just as we can compute areas, arc lengths, and volumes for Cartesian and parametric curves, we can do the same for curves given in polar form. The calculus is adapted to account for the radial structure of polar coordinates, leading to elegant formulas for area and arc length.

Theory

Theorem: Area in Polar Coordinates

For a region bounded by a polar curve $r = f(\theta)$ and the rays $\theta = \alpha$ and $\theta = \beta$, the area is: $$A = \frac{1}{2}\int_{\alpha}^{\beta} r^2\,d\theta$$

This formula comes from the fact that a thin wedge-shaped sector of angle $d\theta$ and radius $r$ has area $\frac{1}{2}r^2 d\theta$.

Theorem: Area Between Two Polar Curves

If two curves $r = f(\theta)$ and $r = g(\theta)$ with $f(\theta) \geq g(\theta)$ enclose a region from $\theta = \alpha$ to $\theta = \beta$, the area is: $$A = \frac{1}{2}\int_{\alpha}^{\beta} \left[f(\theta)^2 - g(\theta)^2\right]\,d\theta$$

This is the area swept out by the outer curve minus the area swept out by the inner curve.

Theorem: Arc Length in Polar Coordinates

For a curve $r = f(\theta)$ from $\theta = \alpha$ to $\theta = \beta$, the arc length is: $$L = \int_{\alpha}^{\beta} \sqrt{r^2 + \left(\frac{dr}{d\theta}\right)^2}\,d\theta$$

This formula reflects that the position changes both radially (through $dr$) and angularly (through $r d\theta$).

💡 Pro Tip

The area formula $A = \frac{1}{2}\int r^2 d\theta$ is elegant because it avoids the need for double integrals. For Cartesian regions, we might need integration with respect to $x$ and $y$, but polar coordinates naturally simplify radial regions.

⚠️ Common Mistake

When finding areas between two curves, always determine which curve is the outer curve in each angular region. The formula requires $f(\theta) \geq g(\theta)$, so be careful about where curves intersect and which is larger in different intervals.

Method

For Finding Area Inside a Polar Curve:

  1. Identify the bounds: if the curve is complete, use $\alpha = 0$ and $\beta = 2\pi$ (or appropriate limits).
  2. Set up: $A = \frac{1}{2}\int_{\alpha}^{\beta} r^2\,d\theta$
  3. Substitute $r = f(\theta)$ and evaluate the integral.

For Finding Area Between Two Polar Curves:

  1. Identify where the curves intersect (set $f(\theta) = g(\theta)$).
  2. Determine which curve is outer and which is inner in each region.
  3. Set up: $A = \frac{1}{2}\int_{\alpha}^{\beta} \left[r_{\text{outer}}^2 - r_{\text{inner}}^2\right]\,d\theta$
  4. Evaluate the integral.

For Finding Arc Length:

  1. Compute $\frac{dr}{d\theta}$
  2. Form the integrand: $\sqrt{r^2 + (dr/d\theta)^2}$
  3. Evaluate $\int_{\alpha}^{\beta} \sqrt{r^2 + (dr/d\theta)^2}\,d\theta$

Examples

Example 1: Area Inside the Cardioid $r = 1 + \cos\theta$
Show Solution ▼

Find the total area enclosed by the cardioid.

The cardioid is traced once as $\theta$ goes from $0$ to $2\pi$.

$$A = \frac{1}{2}\int_0^{2\pi} (1 + \cos\theta)^2\,d\theta$$

Expand: $$(1 + \cos\theta)^2 = 1 + 2\cos\theta + \cos^2\theta$$

Using $\cos^2\theta = \frac{1 + \cos(2\theta)}{2}$: $$1 + 2\cos\theta + \frac{1 + \cos(2\theta)}{2} = \frac{3}{2} + 2\cos\theta + \frac{\cos(2\theta)}{2}$$

$$A = \frac{1}{2}\int_0^{2\pi} \left(\frac{3}{2} + 2\cos\theta + \frac{\cos(2\theta)}{2}\right)\,d\theta$$

$$= \frac{1}{2}\left[\frac{3\theta}{2} + 2\sin\theta + \frac{\sin(2\theta)}{4}\right]_0^{2\pi}$$

$$= \frac{1}{2}\left[\frac{3 \cdot 2\pi}{2} + 0 + 0\right] = \frac{1}{2} \cdot 3\pi = \frac{3\pi}{2}$$

Example 2: Area Inside $r = 3\cos\theta$ and Outside $r = 1 + \cos\theta$
Show Solution ▼

Find the area of the region inside the first curve but outside the second.

First, find intersection points by setting $3\cos\theta = 1 + \cos\theta$: $$2\cos\theta = 1 \implies \cos\theta = \frac{1}{2} \implies \theta = \frac{\pi}{3}, \frac{5\pi}{3}$$

For $\theta \in [-\frac{\pi}{3}, \frac{\pi}{3}]$, we have $r = 3\cos\theta \geq r = 1 + \cos\theta$.

By symmetry about the x-axis: $$A = 2 \cdot \frac{1}{2}\int_0^{\pi/3} [(3\cos\theta)^2 - (1 + \cos\theta)^2]\,d\theta$$

$$= \int_0^{\pi/3} [9\cos^2\theta - (1 + 2\cos\theta + \cos^2\theta)]\,d\theta$$

$$= \int_0^{\pi/3} [8\cos^2\theta - 2\cos\theta - 1]\,d\theta$$

Using $\cos^2\theta = \frac{1 + \cos(2\theta)}{2}$: $$= \int_0^{\pi/3} [4(1 + \cos(2\theta)) - 2\cos\theta - 1]\,d\theta$$

$$= \int_0^{\pi/3} [3 + 4\cos(2\theta) - 2\cos\theta]\,d\theta$$

$$= \left[3\theta + 2\sin(2\theta) - 2\sin\theta\right]_0^{\pi/3}$$

$$= 3 \cdot \frac{\pi}{3} + 2\sin\frac{2\pi}{3} - 2\sin\frac{\pi}{3} - 0$$

$$= \pi + 2 \cdot \frac{\sqrt{3}}{2} - 2 \cdot \frac{\sqrt{3}}{2} = \pi$$

Example 3: Arc Length of the Spiral $r = e^{\theta}$ from $\theta = 0$ to $\theta = 2\pi$
Show Solution ▼

Find the arc length of the logarithmic spiral.

We have $r = e^{\theta}$ and $\frac{dr}{d\theta} = e^{\theta}$.

$$L = \int_0^{2\pi} \sqrt{(e^{\theta})^2 + (e^{\theta})^2}\,d\theta = \int_0^{2\pi} \sqrt{2e^{2\theta}}\,d\theta$$

$$= \sqrt{2}\int_0^{2\pi} e^{\theta}\,d\theta = \sqrt{2}\left[e^{\theta}\right]_0^{2\pi}$$

$$= \sqrt{2}(e^{2\pi} - 1)$$

Numerically, $e^{2\pi} \approx 535.5$, so $L \approx \sqrt{2}(535.5 - 1) \approx 756.3$.

Practice Problems

Practice Problem 1
Show Solution ▼

Find the area inside the circle $r = 2\sin\theta$.

The circle $r = 2\sin\theta$ is traced once as $\theta$ goes from $0$ to $\pi$.

$$A = \frac{1}{2}\int_0^{\pi} (2\sin\theta)^2\,d\theta = \frac{1}{2}\int_0^{\pi} 4\sin^2\theta\,d\theta$$

$$= 2\int_0^{\pi} \sin^2\theta\,d\theta = 2\int_0^{\pi} \frac{1 - \cos(2\theta)}{2}\,d\theta$$

$$= \int_0^{\pi} (1 - \cos(2\theta))\,d\theta = \left[\theta - \frac{\sin(2\theta)}{2}\right]_0^{\pi}$$

$$= \pi - 0 - 0 + 0 = \pi$$

Area = $\pi$ (This matches a circle of radius 1, as $r = 2\sin\theta$ is equivalent to $(x - 0)^2 + (y - 1)^2 = 1$.)

Practice Problem 2
Show Solution ▼

Find the area inside one petal of the rose curve $r = \sin(3\theta)$.

The rose $r = \sin(3\theta)$ has 3 petals. One petal is traced as $\theta$ goes from $0$ to $\frac{\pi}{3}$ (where $r$ goes from 0 to 1 back to 0).

$$A = \frac{1}{2}\int_0^{\pi/3} \sin^2(3\theta)\,d\theta$$

Using $\sin^2(u) = \frac{1 - \cos(2u)}{2}$: $$= \frac{1}{2}\int_0^{\pi/3} \frac{1 - \cos(6\theta)}{2}\,d\theta = \frac{1}{4}\int_0^{\pi/3} (1 - \cos(6\theta))\,d\theta$$

$$= \frac{1}{4}\left[\theta - \frac{\sin(6\theta)}{6}\right]_0^{\pi/3}$$

$$= \frac{1}{4}\left[\frac{\pi}{3} - \frac{\sin(2\pi)}{6} - 0 + 0\right] = \frac{1}{4} \cdot \frac{\pi}{3} = \frac{\pi}{12}$$

Area of one petal = $\frac{\pi}{12}$

Practice Problem 3
Show Solution ▼

Find the arc length of $r = \theta$ (Archimedean spiral) from $\theta = 0$ to $\theta = \pi$.

We have $r = \theta$ and $\frac{dr}{d\theta} = 1$.

$$L = \int_0^{\pi} \sqrt{\theta^2 + 1}\,d\theta$$

This integral requires the substitution $\theta = \sinh(u)$, or we can use the formula: $$\int \sqrt{\theta^2 + 1}\,d\theta = \frac{\theta\sqrt{\theta^2 + 1}}{2} + \frac{1}{2}\sinh^{-1}(\theta) + C$$

Evaluating at the bounds: $$L = \left[\frac{\theta\sqrt{\theta^2 + 1}}{2} + \frac{1}{2}\sinh^{-1}(\theta)\right]_0^{\pi}$$

$$= \frac{\pi\sqrt{\pi^2 + 1}}{2} + \frac{1}{2}\sinh^{-1}(\pi) - 0$$

Numerically: $\pi^2 + 1 \approx 10.87$, so $\sqrt{\pi^2 + 1} \approx 3.297$, and $\sinh^{-1}(\pi) \approx 1.86$.

$$L \approx \frac{3.14159 \cdot 3.297}{2} + \frac{1.86}{2} \approx 5.18 + 0.93 \approx 6.11$$
