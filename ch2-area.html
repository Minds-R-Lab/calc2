Chapter 2.1: Area Between Curves

Introduction

Learning Objectives
  • Find intersection points of two curves algebraically
  • Determine which function is on top in a given interval
  • Calculate the area between two curves using vertical integration
  • Apply horizontal integration when necessary
  • Handle regions where curves intersect multiple times

In this chapter, we extend the concept of the definite integral from finding the area under a single curve to finding the area between two curves. This is a fundamental application of integration and will lead us to volumes of solids of revolution in subsequent chapters.

The key insight is that the area between two curves is the integral of the difference of their functions over the interval of integration.

Theory

Definition: Area Between Curves

The area of the region between two curves $f(x)$ and $g(x)$ from $x = a$ to $x = b$ is:

$$A = \int_a^b |f(x) - g(x)| \, dx$$

When $f(x) \geq g(x)$ on $[a, b]$, the absolute value can be removed:

$$A = \int_a^b [f(x) - g(x)] \, dx$$

💡 Pro Tip

Key Principle: "Top minus bottom" (for vertical integration) or "right minus left" (for horizontal integration). Always subtract the lower function from the upper function to get a positive area.

Definition: Horizontal Integration

If it's easier to express $x$ as a function of $y$, you can integrate with respect to $y$:

$$A = \int_c^d [f(y) - g(y)] \, dy$$

where $f(y) \geq g(y)$ (right minus left).

Method: Finding Intersection Points and Setting Up Integrals

Steps to Find Area Between Curves
  1. Find intersection points: Solve $f(x) = g(x)$ to find where the curves meet
  2. Determine the top function: Evaluate both functions at a test point in each interval to see which is larger
  3. Set up the integral: Use $A = \int_a^b [\text{top} - \text{bottom}] \, dx$
  4. Split if needed: If curves intersect multiple times, split into multiple integrals
  5. Evaluate: Find the antiderivative and apply the Fundamental Theorem of Calculus
⚠️ Common Mistake

Don't forget to check which function is on top! A function that is "below" at one point might be "above" at another if the curves intersect. Always test a point or use the original functions to verify.

To find where two curves intersect, set them equal: $f(x) = g(x)$ and solve for $x$.

Once you have the intersection points, you must determine which curve is above the other in each interval. This is typically done by:

  • Evaluating both functions at a test point in each interval
  • Comparing which value is larger

If the curves intersect multiple times, you may need to split the integral into multiple parts.

Examples

Example 1: Area Between $y = x^2$ and $y = x$

Find the area between the curves $y = x^2$ and $y = x$.

Solution ▼

Step 1: Find intersection points

$$x^2 = x$$ $$x^2 - x = 0$$ $$x(x - 1) = 0$$ $$x = 0 \text{ or } x = 1$$

Step 2: Determine which function is on top

At $x = 0.5$: $y = 0.5$ (linear) and $y = 0.25$ (quadratic). So $y = x$ is above $y = x^2$.

Step 3: Set up and evaluate the integral

$$A = \int_0^1 (x - x^2) \, dx$$ $$= \left[\frac{x^2}{2} - \frac{x^3}{3}\right]_0^1$$ $$= \frac{1}{2} - \frac{1}{3} - 0$$ $$= \frac{3 - 2}{6} = \frac{1}{6}$$

Example 2: Area Between $y = \sin x$ and $y = \cos x$ on $[0, \pi/2]$

Find the area enclosed between $y = \sin x$ and $y = \cos x$ on the interval $[0, \pi/2]$.

Solution ▼

Step 1: Find intersection points in $[0, \pi/2]$

$$\sin x = \cos x$$ $$\tan x = 1$$ $$x = \frac{\pi}{4}$$

Step 2: Determine which function is on top

On $[0, \pi/4]$: $\cos x \geq \sin x$ (e.g., at $x=0$, $\cos 0 = 1 > 0 = \sin 0$)
On $[\pi/4, \pi/2]$: $\sin x \geq \cos x$ (e.g., at $x = \pi/2$, $\sin(\pi/2) = 1 > 0 = \cos(\pi/2)$)

Step 3: Set up and evaluate the integral

$$A = \int_0^{\pi/4} (\cos x - \sin x) \, dx + \int_{\pi/4}^{\pi/2} (\sin x - \cos x) \, dx$$ $$= \left[\sin x + \cos x\right]_0^{\pi/4} + \left[-\cos x - \sin x\right]_{\pi/4}^{\pi/2}$$ $$= \left(\frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2}\right) - (0 + 1) + \left(0 - 1\right) - \left(-\frac{\sqrt{2}}{2} - \frac{\sqrt{2}}{2}\right)$$ $$= \sqrt{2} - 1 - 1 + \sqrt{2}$$ $$= 2\sqrt{2} - 2 = 2(\sqrt{2} - 1)$$

Example 3: Area Enclosed by $x = y^2$ and $x = 4$

Find the area enclosed by the parabola $x = y^2$ and the vertical line $x = 4$.

Solution ▼

Step 1: Find intersection points

$$y^2 = 4 \implies y = \pm 2$$

Step 2: Integrate with respect to $y$ (horizontal integration)

For $y \in [-2, 2]$, the right curve is $x = 4$ and the left curve is $x = y^2$.

$$A = \int_{-2}^{2} (4 - y^2) \, dy$$ $$= \left[4y - \frac{y^3}{3}\right]_{-2}^{2}$$ $$= \left(8 - \frac{8}{3}\right) - \left(-8 + \frac{8}{3}\right)$$ $$= 8 - \frac{8}{3} + 8 - \frac{8}{3}$$ $$= 16 - \frac{16}{3} = \frac{48 - 16}{3} = \frac{32}{3}$$

Practice Problems

Practice Problem 1

Find the area between the curves $y = 2x$ and $y = x^2 - 3$ between their intersection points.

Show Solution ▼

First, find intersections: $2x = x^2 - 3 \implies x^2 - 2x - 3 = 0 \implies (x-3)(x+1) = 0$, so $x = -1$ or $x = 3$.

At $x = 0$: $y = 0$ (line) vs $y = -3$ (parabola), so the line is above.

$$A = \int_{-1}^{3} (2x - (x^2 - 3)) \, dx = \int_{-1}^{3} (-x^2 + 2x + 3) \, dx$$ $$= \left[-\frac{x^3}{3} + x^2 + 3x\right]_{-1}^{3}$$ $$= \left(-9 + 9 + 9\right) - \left(\frac{1}{3} + 1 - 3\right) = 9 - \frac{1}{3} + 2 = \frac{32}{3}$$

Practice Problem 2

Find the area of the region bounded by $y = e^x$, $y = 0$, $x = 0$, and $x = 1$.

Show Solution ▼

This is simply the area under the curve $y = e^x$ from 0 to 1.

$$A = \int_0^1 e^x \, dx = \left[e^x\right]_0^1 = e - 1$$

Practice Problem 3

Find the area enclosed by $x = y^2 - 2$ and $x = y$.

Show Solution ▼

Find intersections: $y = y^2 - 2 \implies y^2 - y - 2 = 0 \implies (y-2)(y+1) = 0$, so $y = -1$ or $y = 2$.

At $y = 0$: $x = 0$ (line) vs $x = -2$ (parabola), so the line is to the right.

$$A = \int_{-1}^{2} (y - (y^2 - 2)) \, dy = \int_{-1}^{2} (-y^2 + y + 2) \, dy$$ $$= \left[-\frac{y^3}{3} + \frac{y^2}{2} + 2y\right]_{-1}^{2}$$ $$= \left(-\frac{8}{3} + 2 + 4\right) - \left(\frac{1}{3} + \frac{1}{2} - 2\right) = \frac{10}{3} + \frac{1}{2} + \frac{1}{3} + 2 = 9$$
