3.1 Type I Improper Integrals — Infinite Intervals

Learning Objectives
  • Understand the definition of Type I improper integrals with infinite endpoints
  • Learn to evaluate improper integrals using limits
  • Distinguish between convergent and divergent integrals
  • Apply the $p$-test to determine convergence of power functions

In elementary calculus, we define the Riemann integral $\int_a^b f(x)\,dx$ for bounded intervals $[a,b]$. But what happens when one or both endpoints are infinite? A Type I improper integral is an integral where the interval of integration is unbounded: we integrate to $\infty$ or from $-\infty$.

This section explores how to evaluate integrals over infinite intervals by using limits, when they converge to finite values, and when they diverge to infinity.

Definition and Theory

Definition: Type I Improper Integral (Upper Limit at Infinity)

For a function $f$ that is continuous on $[a, \infty)$, we define:

$$\int_a^{\infty} f(x)\,dx = \lim_{t \to \infty} \int_a^t f(x)\,dx$$

The improper integral converges if the limit exists and is finite. Otherwise, it diverges.

Definition: Type I Improper Integral (Lower Limit at Negative Infinity)

For a function $f$ that is continuous on $(-\infty, b]$:

$$\int_{-\infty}^b f(x)\,dx = \lim_{t \to -\infty} \int_t^b f(x)\,dx$$
Definition: Type I Improper Integral (Both Limits at Infinity)

For a function $f$ that is continuous on $(-\infty, \infty)$, we split the integral:

$$\int_{-\infty}^{\infty} f(x)\,dx = \int_{-\infty}^c f(x)\,dx + \int_c^{\infty} f(x)\,dx$$

where $c$ is any point (often $c=0$). The double integral converges if and only if both parts converge.

Theorem: The $p$-Test for Type I Integrals

One of the most important results for Type I integrals is the $p$-test:

$$\int_1^{\infty} \frac{1}{x^p}\,dx \quad \text{converges if and only if} \quad p > 1$$

When the integral converges (i.e., $p > 1$), the value is:

$$\int_1^{\infty} \frac{1}{x^p}\,dx = \frac{1}{p-1}$$

This is a fundamental comparison tool for determining convergence of other integrals.

💡 Pro Tip: Pattern Recognition

The $p$-test is incredibly useful. When you see an integral with the form $\frac{1}{x^p}$ or something that behaves similarly at infinity, you can immediately determine convergence by checking if $p > 1$. Keep this benchmark in mind when using comparison tests!

Method for Solving

  1. Set up the limit: Replace the infinite endpoint with a variable $t$ and write $$\int_a^{\infty} f(x)\,dx = \lim_{t \to \infty} \int_a^t f(x)\,dx$$
  2. Compute the antiderivative: Find an antiderivative $F(x)$ of $f(x)$.
  3. Evaluate the finite integral: $$\int_a^t f(x)\,dx = F(t) - F(a)$$
  4. Take the limit: Compute $$\lim_{t \to \infty} [F(t) - F(a)]$$
  5. Determine convergence: If the limit is a finite number, the integral converges to that value. If the limit is $\pm\infty$ or does not exist, the integral diverges.
Key Insights
  • Exponential decay functions (like $e^{-x}$) almost always lead to convergence.
  • Polynomial terms in denominators ($1/x^p$) converge only if the power is large enough ($p > 1$).
  • Oscillating functions (like $\sin x$) typically lead to divergence for Type I integrals.
⚠️ Common Mistake: Forgetting the Limit

Many students try to directly antidifferentiate and evaluate at infinity, like $[F(x)]_a^{\infty}$. This is informal notation! You must set up the limit first: $\lim_{t \to \infty} [F(t) - F(a)]$. This ensures you're correctly analyzing the limiting behavior.

Worked Examples

Example 1: $\displaystyle \int_1^{\infty} \frac{1}{x^2}\,dx$ (Converges)

Problem: Evaluate the improper integral or show that it diverges.

Solution ▼
  1. Set up the limit: $$\int_1^{\infty} \frac{1}{x^2}\,dx = \lim_{t \to \infty} \int_1^t x^{-2}\,dx$$
  2. Find the antiderivative: $F(x) = -\frac{1}{x}$
  3. Evaluate: $$\int_1^t x^{-2}\,dx = \left[-\frac{1}{x}\right]_1^t = -\frac{1}{t} - \left(-\frac{1}{1}\right) = -\frac{1}{t} + 1$$
  4. Take the limit: $$\lim_{t \to \infty} \left(-\frac{1}{t} + 1\right) = 0 + 1 = 1$$

Conclusion: The integral converges to $\boxed{1}$. This also confirms the $p$-test with $p=2 > 1$: $$\int_1^{\infty} \frac{1}{x^2}\,dx = \frac{1}{2-1} = 1 \,\checkmark$$

Example 2: $\displaystyle \int_1^{\infty} \frac{1}{x}\,dx$ (Diverges)

Problem: Evaluate the improper integral or show that it diverges.

Solution ▼
  1. Set up the limit: $$\int_1^{\infty} \frac{1}{x}\,dx = \lim_{t \to \infty} \int_1^t \frac{1}{x}\,dx$$
  2. Find the antiderivative: $F(x) = \ln|x| = \ln x$ (for $x > 0$)
  3. Evaluate: $$\int_1^t \frac{1}{x}\,dx = [\ln x]_1^t = \ln t - \ln 1 = \ln t$$
  4. Take the limit: $$\lim_{t \to \infty} \ln t = \infty$$

Conclusion: The integral diverges to $\infty$. The $p$-test with $p=1$ predicts divergence: we need $p > 1$ for convergence. $\checkmark$

Example 3: $\displaystyle \int_0^{\infty} e^{-x}\,dx$ (Converges)

Problem: Evaluate the improper integral or show that it diverges.

Solution ▼
  1. Set up the limit: $$\int_0^{\infty} e^{-x}\,dx = \lim_{t \to \infty} \int_0^t e^{-x}\,dx$$
  2. Find the antiderivative: $F(x) = -e^{-x}$
  3. Evaluate: $$\int_0^t e^{-x}\,dx = \left[-e^{-x}\right]_0^t = -e^{-t} - (-e^{0}) = -e^{-t} + 1$$
  4. Take the limit: $$\lim_{t \to \infty} \left(-e^{-t} + 1\right) = 0 + 1 = 1$$

Conclusion: The integral converges to $\boxed{1}$. Exponential decay is powerful!

Practice Problems

Practice Problem 1

Evaluate the improper integral or show that it diverges: $$\int_2^{\infty} \frac{1}{x^3}\,dx$$

Show Solution ▼

By the $p$-test with $p=3 > 1$, this converges. Using antiderivative $F(x) = -\frac{1}{2x^2}$:

$$\int_2^{\infty} x^{-3}\,dx = \lim_{t \to \infty} \left[-\frac{1}{2x^2}\right]_2^t = \lim_{t \to \infty} \left(-\frac{1}{2t^2} + \frac{1}{8}\right) = \frac{1}{8}$$
Practice Problem 2

Determine whether the following improper integral converges or diverges: $$\int_1^{\infty} \frac{x}{x^2+1}\,dx$$

Show Solution ▼

Let $u = x^2 + 1$, so $du = 2x\,dx$. Then:

$$\int_1^t \frac{x}{x^2+1}\,dx = \frac{1}{2}\int_2^{t^2+1} \frac{du}{u} = \frac{1}{2}[\ln u]_2^{t^2+1} = \frac{1}{2}\ln(t^2+1) - \frac{1}{2}\ln 2$$

As $t \to \infty$, we have $\ln(t^2+1) \to \infty$, so the integral diverges.

Practice Problem 3

Evaluate or show that it diverges: $$\int_0^{\infty} e^{-2x}\,dx$$

Show Solution ▼

The antiderivative of $e^{-2x}$ is $F(x) = -\frac{1}{2}e^{-2x}$. Therefore:

$$\int_0^{\infty} e^{-2x}\,dx = \lim_{t \to \infty} \left[-\frac{1}{2}e^{-2x}\right]_0^t = \lim_{t \to \infty}\left(-\frac{1}{2}e^{-2t} + \frac{1}{2}\right) = \frac{1}{2}$$

The integral converges to $\displaystyle \frac{1}{2}$.
